# 四组逐帧基准点回放根因分析

基线：NextRound OpenCV440 r1，提交 92a687d，DLL 104365e1…180c。更早冻结 DLL e55e5d5a…cd23。此次在独立工程中保留原件后继续开发；二进制身份见 config/modes.json 与 baseline/identity.json。

## 输入与比较口径

用户已明确确认：num=0 对应第一张参考图，num=1 对应第二张图；全部为未裁剪、未缩放的原图坐标，P1/P2 为同一物理点并保持顺序。1991 行全部通过有限值、边界、最小距离、唯一编号检查；这不代表外部跟踪器没有定位噪声。未发现独立人工裂纹尖端、根部或中心线标注。

主要五组对照统一使用本轮实测参考双点，消除参考点差异。AUTO_REPORT_REPLAY 额外沿用历史手填参考点，逐帧复现已交付报告。因此本轮 AUTO_NEW_SHADOW 的确认数量可能与上一报告略有不同，不能将参考点变化当作算法改进。

## 1. 自动配准返回成功不等于几何正确

原自动模式以相位响应筛选背景块。指定合成 (7,-31) 中，仅一块响应约0.177通过，返回 (-16.233,-0.630)；原阈值允许其成功，导致约360px尖端误差。新独立开关1024在仅一块或平均响应<0.2时触发当前图像独立复核：先做最多两个有界基准点模板匹配，再做最多四块有界背景匹配；原路径数量少本身不判错。复核成立则用当前证据恢复；失败则 AMBIGUOUS，撤销本帧尖端/完整长度确认，保留候选可见路径，历史结果不冒充本帧。

## 4. 方向和当前可见性分别处理

256/512为互斥的 AnchorPositive/AnchorNegative：沿有序 P1→P2 的右法向或反方向。未设置时仍为Auto，保留原亮度判断/方向歧义处理。本四组原图均为上方P1、下方P2、裂纹向右进入材料，视频和复核包中可检查；不作为所有未知试件的默认假设。镜像合成场景另外验证了负法向。

保留已有64的纹理消失审计，并新增2048使其在Shadow策略下也能撤销本帧形式确认：当末端前方13×7有效采样中，参考仍有纹理且未饱和、当前接近常值时，不将可见截断点当物理尖端。仅复用已有统计，不引入全图计算、不强加单调长度。当前跟踪终点、根部、路径继续提供。

## 6. 过曝和遮挡的限制

CT2加25灰度会把原始>=230像素映射为255，多个不同像素变成同值。实测双点只能隔离几何误差，不能恢复这些丢失的暗线细节。反例的实测点、纯刚体/细化、增益/饱和消融见 ct2_photometric_causality.json。新增局部常值保护仅覆盖被实际采样并满足条件的失效，不能保证检测所有过曝或真实遮挡。一般阴影、低对比度和裂纹闭合仍需人工复核；可见长度允许回落。

## 本轮实测发现的多块一致误配边界

开发组H源frame_id=12（20250314143256527-3316.bmp）中，AUTO_NEW_SHADOW返回成功，两个块、响应0.481，平移y=+31.395；实测双点细化后y=-35.728。对第二实测点的残差分别为66.848px与1.716px。keyframes/group_h_max_residual.png显示自动预测的参考点偏离实测孔中心。相位相关循环位移/重复纹理是可能原因；已有数据足以确认两条几何结果明显不一致，但尚不足以将所有大残差解释为同一种机制。

1024针对低置信成功的复核不会触发这一“多个块一致且响应较高”的例子；没有声称所有自动误配均已解决。本轮正式候选使用提供的真实当前双点，绕开这一自动误配路径。缺少外部点时AUTO_OPT仍保留实验状态。
