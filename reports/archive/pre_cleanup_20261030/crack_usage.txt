疲劳裂纹自动追踪与像素测量
========================

更新：逐帧两个追踪基准点、clean/cracked 两种参考帧、mm 长度及四列业务 CSV，
请先阅读同目录 tracked_crack_usage.txt。已有的 ANCHOR_POINTS 和自动平移模式仍兼容。

直接运行
--------
打开 crack_measurement.py，只需修改文件最上方：
  IMAGE_PATH = r"你的图像文件夹"
  ANCHOR_POINTS = ((2245.0, 2255.0), (2245.0, 2438.0))

两点是第一张参考帧中缺口两侧的原图像素坐标。
同一试验、同一相机位置只需要提供一次，不需要逐帧点击。
随后直接点击编辑器“运行”，无需填写命令行参数。
文件夹按自然数字顺序排列，第一张为固定参考，后续图像分别与它比较。
支持 1.bmp、21.bmp，也支持 1 (1).bmp、4 (170).bmp 等序列命名。
单独输入一个编号序列文件时，自动寻找同目录的第一张序列图作为参考。
程序支持中文路径，不修改原始图像。

默认输出
--------
结果放在参考图所在文件夹的 crack_results_auto 中，保留以前的 crack_results。
每张输入图像生成一张三联汇总 PNG：
  左：完整原图及自动放大范围。
  中：整条已追踪主裂纹的中心线。
  右：检测尖端或未确认终点，标注原图像素坐标。
  下：像素弧长、起点、终点、外推量、追踪窗口数量、停止原因和计算耗时。
放大范围随裂纹路径自动扩大，不会只显示原先固定 ROI 内的一段。
另输出 measurements.csv、measurements.json，以及逐点中心线 CSV。
坐标以各自原图左上角为 (0,0)，x 向右，y 向下。

算法如何自动扩展
----------------
1. 从两个基准点建立缺口局部坐标系，以参考图材料亮度自动判断扩展侧。
2. 自动选择缺口附近的多个纹理块，估计当前帧相对参考帧的平移。
3. 在缺口边界附近自动寻找新增暗线，不需要手填处理 ROI 或搜索 ROI。
4. 用局部有方向的线响应和参考差分联合判断裂纹证据。
5. 在当前路径前方建立移动窗口；随着裂纹弯曲，窗口不断平移和旋转，
   因此裂纹可以向下或向上扩展，不再要求整条路径的原图 x 坐标单调。
6. 默认每次前进至多 48 像素，先观察前方 96 像素，再决定是否继续。
   局部窗口边缘不是裂纹终点，后续窗口会继续检查。
7. 前方证据不足时，输出当前可见裂纹段的尖端估计。
   到达图像/材料边界、长断点、回环或安全次数上限时，
   输出 tracking_incomplete，tip_original_xy 为空，保留已追踪终点。
   不把这些截断状态当作已确认尖端。

测量口径
--------
弧长沿平滑后的中心线累计，不使用包围框宽度。
起点附近不足以直接辨识的短段可外推，并单独报告外推长度。
短断点可插值，中心线 CSV 的 segment_type 会标明插值与外推。
目前追踪一条主裂纹；复杂分叉不保证同时测量所有分支。
tip_confirmed 只表示算法没有遇到边界/长断点等未完成状态，
不代表经过独立测量验证的物理裂尖真值。
低对比度末端、遮挡和反光仍可能带来漏提，需要结合原图或时间序列核验。
不强制裂纹长度单调增长，以免掩盖裂纹开闭或识别失败。

运行与依赖
----------
入口：crack_measurement.py
自动追踪模块：adaptive_crack.py
旧版固定 ROI 模块：crack_realtime_demo.py
安装依赖：python -m pip install -r requirements.txt
crack_measurement.py、adaptive_crack.py、crack_realtime_demo.py、crack_inputs.py 应放在同一目录。

仍支持可选命令行：
  python crack_measurement.py "图像文件夹"
  python crack_measurement.py "4 (170).bmp" --reference "1 (1).bmp"
  python crack_measurement.py "图像文件夹" --output "输出文件夹"
  python crack_measurement.py "图像文件夹" --anchors 2245 2255 2245 2438
  python crack_measurement.py "图像文件夹" --benchmark 100
  python crack_measurement.py --help

默认没有固定处理 ROI。只有显式传入 --roi X Y W H 才进入旧版固定区域模式。
--view 只控制显示区域；默认不传，随整条路径自动调整。
--threshold 控制裂纹证据阈值；--max-shift 控制配准允许的最大平移。
--threads 控制 OpenCV CPU 线程数；--font 可指定中文字体。
--benchmark 的时间只包含内存中的配准、追踪和像素测量。
在线 15 Hz 时应把汇总图绘制/显示/存盘放到单独线程或降低绘图频率。

验证
----
python -m unittest test_adaptive_crack -v
已包含已知几何路径的弯曲追踪、平移、参考帧、长断点、
图像边界、基准点顺序等合成回归检查。
真实数据的无标签抽样运行用于检查稳定性，不等同于准确率评估。
