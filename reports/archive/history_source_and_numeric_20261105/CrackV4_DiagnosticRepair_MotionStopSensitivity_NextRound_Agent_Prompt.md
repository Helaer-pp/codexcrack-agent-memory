## 4. Phase 1：把诊断修复为可解释的分层系统（核心工作一）

### 4.1 拆分三个不同目标，禁止共享一个 `image_good` 总门控

为每帧独立定义并存储：

- `CURRENT_DARK_LINE_OBSERVABLE`：当前图像沿冻结 A 的既有路径是否具有足够的横截面暗谷/线性结构证据；只证明可观察的暗线形态，不证明是真裂纹。
- `REFERENCE_CHANGE_EVALUABLE`：参考帧和当前帧在相关材料坐标、光度范围及独立局部匹配上是否足以进行变化解释；不能由 CURRENT 直接推导。
- `MATERIAL_MOTION_EVALUABLE`：是否具有独立于 P1/P2 拟合点的材料位移观测；报告实际有效样本、位置跨度及不确定性，不因无样本而把运动误差写 0。

各自保存 `PASS/FAIL/UNKNOWN`、`reason[]` 和分母。既有光度失败不能直接导致“当前暗线不存在”；P1 通过也不自动提升参考变化安全性。

### 4.2 光度 / 编码信息实验

至少对 `材料背景 / 候选路径中央 / 路径两侧 / 锚点邻域 / 黑孔或非材料` 分区分别统计：

- 8-bit histogram；`I<=20`、`I>=250`、`I==255` 分开；区分高亮但有结构和编码平坦区域。
- 局部 `P10/P50/P90/P99`、动态范围、梯度方差、局部高频 MAD（只标噪声代理）、灰度量化台阶、连通平坦斑块。
- 同一条固定 A 路径上的暗谷响应与两侧背景对比、有效取样数量；明确路径本身引入的条件化选择偏差。
- 与参考图比较时，**必须先验证局部对应和光度一致性**；无对应时写 `REFERENCE_CHANGE_EVALUABLE=UNKNOWN/FAIL`，不能把变暗解释成新裂纹。
- 数字 photometric controls：XOR1、明确已知增益/偏置、仿射亮度与量化、局部渐变、截断（clipping）、伽马变化；可逆浮点变化和量化后不可逆变化分别标注。
- 如果无法接入相机，实际曝光/光源/ADC/加载相位一律 `NOT_TESTED_HARDWARE`，不能用数字扰动替代真实成像结论。

**实验目标**：用同一批 DEV 中已知清晰暗线、无暗线、静态暗纹、渐浅/弯曲弱线作为受控条件，验证“旧高灰度门控失败”的帧是否仍可分辨暗谷与背景，同时统计误把静态纹理当成“新增裂纹”的风险。**不要直接宣称已优化检测精度。**

### 4.3 分层匹配失效诊断：每次尝试都可复现

保留冻结旧规则顺序及原输出，在旁路记录所有条件，不只保留“第一个失败”：

1. 位置/材料区域是否有效：边界、孔洞、ROI、采样区域的材料属性来源及其不确定性。
2. 模板可辨识：方差/中位梯度/局部峰形及重复纹理；不能用高灰度简单推断无纹理。
3. 码值可用性：`<=20`、`>=250`、`==255`、有效动态范围分别计数。
4. 搜索覆盖：`±12` 与 `±24`、正确匹配是否被窗口截断（仅已知运动 GT 能判定）。
5. NCC 匹配峰：最大分数、次峰、peak ratio、峰宽、是否贴边、多个竞争峰。
6. 前后向一致性、局部几何合理性、训练样本空间分布及独立验证样本是否足够。
7. 验证残差仅报告在**有效且独立**的子集，另报该子集选择率和空间覆盖；没有独立验证时 `N/A`。

新增“影子 NCC/影子匹配”只用于对比，绝不替换原先 gate；首次拒绝标签与所有未通过条件必须同时保存，防止因阶段顺序造成假归因。

### 4.4 已知几何 GT 的对照设计（必须有真实负例和错误接受统计）

- 真实无相应结构的匹配负对照、重复伪峰、静态暗纹、多处类似纹理；使错误匹配有机会出现。不能只构造易于拒绝的无纹理负例。
- `±12/±24` 搜索和 NCC 0.60/0.75/0.90 的**预定义矩阵**作为诊断对照，不要求最终采用任何一个阈值。
- 既有一组在旧门控下被拒绝、但已知几何 GT 显示能正确匹配的案例；以及一组高分 NCC 实际匹配错误的反例。

对每个候选诊断方案给出：

`N_all / N_evaluable / N_accepted / N_rejected / N_true_correct / N_false_accept (>0.5 px) / P50/P95 accepted_error / max_error / abstention`。

另按材料组、亮度档、纹理类型、运动幅度、边界以及 DEV/TEST 分层。`>0.5 px` 仅为本轮程序 GT 的预注册容差，不能作为生产真实尖端误差容差。对比必须采用**配对同案例**，展示每个新增通过样本是正确接受还是错误接受，给出率的区间和样本不足声明。

**禁止只比较接受数量或仅报告接受子集 P95。** 当某组 0 个可评价，明确 `INSUFFICIENT_EVIDENCE`，而不是把误接受记成 0%。

### 4.5 多组泛化与诊断选择决策

- 在四折 leave-one-group-out 上评估**固定规则**；每折规则开发仅从其余三组获得，留出组只用于该折评价。
- 使用预先注册的顺序选择：首先限制程序 GT 错误接受风险，其次扩大有效覆盖，最后比较位移误差和计算成本。
- 只要某组某类输入出现不可解释的新增错误接受，方案不得以整体通过帧数高而直接判为改进。
- 如无法找到可靠的诊断修复方案，保留旧门控与新增分类解释，结论为 `PARTIAL / NO_SAFE_REPAIR`，不得强行选参数。

**Phase 1 交付**：

`photometry_features_per_frame.csv`、`diagnostic_states_per_frame.csv`、`match_attempts_all.parquet`（或 CSV）、`first_reject_vs_multilabel.csv`、`shadow_match_comparison.csv`、`known_motion_gt_cases.csv`、`matched_decisions.csv`、`leave_one_group_out_results.csv`、`01_diagnostic_repair_report.md`。

## 5. Phase 2：CT2 运动映射 → 路径延伸／停止敏感性研究（核心工作二）

**本阶段为只读仪表化和受控几何干预，不改变生产 `refine`、`ridge` 的实现。**

### 5.1 保持两个不同问题分离

- **因果传播**：运动矩阵改变是否导致后续采样、seed、路径、延伸 tile、停止条件改变？已有 11/14 的受控证据，应复核并扩展。
- **物理准确性**：哪一个运动矩阵真正对应材料位移，哪一个尖端符合物理裂纹？没有独立材料真实运动或尖端 GT，维持 `UNRESOLVED`。对同一物理对象的正确性不得由配置标签推断。

### 5.2 完整逐变量仪表化

沿原 `motion()`、`refineRoot()`、`tile()`、`seed()`、`ridge()`、`process()` 输出每帧关键状态（每帧粗 trace、预选帧深 trace）：

- 两点刚体初值 R/T；phaseCorrelate 的 patch 位置/响应/偏移、候选及拒绝原因；中位数离群筛选、SVD 使用、平移回退和 no patch 情况；得到的最终 R/T。
- 原参考坐标与 transformed 当前采样坐标、root/seed 窗口、图像灰度、score、mask、starts、reward、penalty。
- 每个 tile 当前/参考矩阵、有效样本数、ridge 最优分数、前驱索引、gain、supported、停止触发原因及编号；原始停止条件不变。
- 原图坐标下的完整 DP 路径、CopyPath、前缀距离、曲率、第一次持续几何分歧、重新汇合；在多容差（1/3/5px）下对照。
- 明确每列最好/次好**端点状态分差**不等于真正 K-best 完整路径的后验差异。

确保深 trace 函数只读，保存变换和采样 hash；不在实时路径写海量文件。

### 5.3 同历史反事实——扩大覆盖而不污染时序

- 复现上轮的 14 个案例，包括 6、18、84 三个重点帧，保持 `auto` 参考模式。
- 同一帧固定 on 版本的 `previous` 和 observation 队列，分别给予 on 与 off 的当帧 R/T；再做对称的固定 off 历史对照。每次独立初始化，不在两个方案之间共享可变指针。
- 对 R/T 做受控已知微扰，建议预注册多个幅度档（包括 0、亚像素以及达到已有映射差量级的几何扰动），旋转中心、方向与坐标系写清；**干预幅度不等于实际配准误差**。
- 每个干预记录：路径是否改变、首次内部差异、共同路径前缀距离、延伸 tile 差、尖端差、路径是否重新汇合、检测状态、是否仅继续延伸；同一帧参考图 hash 与 P1/P2 保持一致。
- 只在前四组开发数据上设计和调整案例选取条件。全 CT2 467 帧至少输出粗 trace；原 19 帧 `INDETERMINATE` 保留为单独高优先集，无法解释的继续报告 `UNEXPLAINED`，**不要为达到 0 未解释而放宽标签定义**。
- 将干预前后输出区分为：`GEOMETRY_ONLY_SHIFT / SEED_OR_ROI_CHANGE / CONTINUATION_DOMINATED / TRUE_GEOMETRIC_BRANCH_DIVERGENCE / REJOIN / NO_EFFECT / INDETERMINATE`。此处 TRUE 只意为“真实的路径几何分叉”，**不是物理真实裂纹分支**。

### 5.4 量化“停止敏感性”而不是修改 STOP

针对 frame 6/18/84 和代表性短路径/长路径案例：

1. 精确重建同一冻结 C++ `ridge()` 的 tile 输入矩阵、终止列、gain、supported 与原 process 停止理由；必须与原 trace 一致。
2. 记录哪些受控运动映射变化使某个 tile 从 `supported>=3 且 gain>=4` 变为触发停止；区分“根部/seed 先改变”和“同一主体延伸但停止 tile 改变”。
3. 对每帧生成**运动输入敏感度曲线**：干预幅度 vs 首次分歧、停止 tile、尖端位移、确认状态；给出是否出现非连续阈值跳变。
4. 估计无 GT 下的“可观察不确定范围”：只能称为在给定干预集合下的**输出敏感区间**，不能宣称是正确尖端的可信区间或误差上界。
5. 在没有真正已知局部材料运动的图像上，对 on/off 不选胜者；即使一种配置更稳定，也不代表物理上更准确。
6. 对具有程序已知运动 GT 的半合成场景，单独计算运动估计错误及其对 DP 输出的影响，明确 GT 是运动，不是物理裂纹尖端；如果合成注入了已知裂纹，再另列真实合成尖端误差。

**Phase 2 交付**：

`ct2_refine_trace_all.csv`、`motion_counterfactual_cases.csv`、`geometry_perturbation_grid.csv`、`first_internal_difference.csv`、`dp_tile_stop_trace.csv`、`continuation_vs_branch.csv`、`stop_sensitivity_curves.csv`、`ct2_unexplained_19_review.md`、`02_ct2_motion_stop_report.md`。

**Gate 2：** 能独立复现已知因果链，区分至少三类不同几何/停止机制，并在受控干预中一致解释起始、延伸和停止的影响；对剩余未解释的案例明确标记。**这只能认定为根因诊断增强，不等于修复尖端精度。**

## 10. 最终决策规则与回复格式

最终只能在以下**研究结论**中选择，并给出证据链：

- `DIAGNOSTIC_REPAIR_VALIDATED`：诊断修复通过预注册的独立 GT 风险/覆盖要求；**生产 A 仍不变**。
- `DIAGNOSTIC_REPAIR_PARTIAL`：只有部分材质或已知几何条件获得收益；清楚标出限制与反例。
- `DIAGNOSTIC_REPAIR_NOT_PROVEN`：仅说明旧规则有限，未证明新诊断在独立条件下更可靠。
- `GEOMETRY_SENSITIVITY_CHARACTERIZED`：CT2 受控运动扰动与停止链可重建；**不等于物理尖端正确性得到提升**。
- `STOP_OR_UNEXPLAINED`：A 复现失败、控制实验存在污染、必要文件缺失或证据不足时，停止错误归因，交付已完成部分。

可并列一项诊断结果与一项 CT2 机制结果，但生产默认决策固定为 **`KEEP_FROZEN_A`**。绝对禁止将“不确定的拒绝结果更多”“诊断通过率更高”“停止位置改变”写成真实精度改善。

### Agent 最终回复须包含

1. **代码开发成果**：实际修改了哪些诊断文件、提交 ID、diff 和编译结果；明确生产 DLL 没有变化。
2. **四组核心对照表**：旧/新诊断可评价率，GT 匹配正确接受及错误接受，按组/纹理/变换强度分层。
3. **CT2 可复现因果结果**：前 14 帧复现状态、6/18/84 关键停止 tile、19 帧未解释归因、受控敏感曲线。
4. **失败案例和风险**：至少列出新增误接受案例、配准无观测案例、渐浅/弯曲/静态纹理反例及其原图索引；若没有合格分母则写 N/A。
5. **性能和交付链接**：P50/P95/P99/Max、完整视频和逐帧诊断 CSV、报告索引、可复现命令与 SHA256。
6. **下一步唯一优先建议**：若诊断改进获得独立支持，可提出下一轮对运动估计的**独立 shadow 候选**研究；如果仍没有可靠的独立材料证据，则优先受控采集，而不是再次修改 DP。不得未经验证发布任何新算法。

> **最终目标不是本轮“修好尖端”**，而是把“何时图像可评价、何时几何输入不可靠、何时 DP 停止对输入异常敏感”变成**可复现、可量化且不会误导精度判断的工程证据**。在此基础上，下一轮才决定是否有资格对冻结 A 进行最小、可解释的正式优化。
