# 变化点与有界尖端重定位

每2px采样。7点滑窗需3强支持建立主体，连续3个主体窗才允许检测后缀损失。低支持窗与CUSUM同时判断，位置相差最多16px；恢复主体会清除内部间隙的旧变化点。

变化点或前方延续/DP分歧触发局部beam=3搜索。回看24px、最大延伸96px、最多64步/576节点。沿局部切向±20度分支，保留弯曲，不强制水平或固定根部朝向。短间隙预算12px。主体暗线与前方至少6个可用负证据样本共同支持末端时才接受新尖端。搜索失败时保留可见前缀或原结果，绝不把CP直接冒充尖端。

原回看12px在合成测试中因窗口检测滞后不足以保留9点主体，改为24px后改善。根部连接上限仍为12px。完整长度若改变，为保留DP段加局部亚像素折线再加有证据的根部连接，未把所有段都改成Hessian弧长。

72个已知路径测试中36条含虚假60px后缀，另36条不含后缀；最终失败数 0。8px仅为该合成测试的断言容差，业务精度门槛尚未提供。

重要限制：DEV-4四组最终变化点触发数均为0，GATED消融在这些实际序列没有改变确认结果。因此合成变化点测试通过不能证明真实纹理长尾已解决。实际结果变化主要来自前方延续或DP分歧触发的有界重定位。任何重定位也没有真实GT可证实位置更准确。
