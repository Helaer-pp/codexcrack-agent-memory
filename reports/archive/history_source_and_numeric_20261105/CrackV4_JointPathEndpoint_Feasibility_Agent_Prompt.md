## 1. 核心研究假设（必须设计可证伪的实验）

### H1：DP 的主要失败来自“没有与背景进行显式竞争”

旧 DP 往往最大化路径响应与平滑性，但较大搜索空间里随机纹理也能得到连续高分。本轮应验证：**局部特征相对于背景负例的增量证据**，是否比原黑帽/累计 DP 分数更能区分裂纹和纹理。

设局部向量 `F(s)=[dark_ridge, cross_profile, reference_change, orientation, width, quality_mask...]`，对候选路径计算正负证据，例如：

`LLR(s) = log p(F(s)|crack) - log p(F(s)|background)`。

这只是候选表达式。可以采用可解释的低维概率模型、正则化逻辑回归或少量经过验证的规则化评分；**不要求神经网络，也不能在无标注时声称是真实概率**。考虑线状 Hessian 与黑帽响应高度相关，不能盲目按独立似然相加。必须用交叉验证/可靠性曲线检查校准、类不平衡和跨组失效。

**H1 可证伪标准**：在四组 held-out 样本的真实裂纹段与背景段上，竞争评分若不能比原始响应显著改善区分，或导致更多弱裂纹误拒绝，则停止该方向或返回 `INCONCLUSIVE`，不可直接上生产。

### H2：单路径贪婪/单一最优 DP 早早选错分支，末端补救无能为力

验证在 DP 第一次进入错误纹理时，正确真实路径是否在次优候选中；保留少量结构不同的候选（建议实验 `K=1,2,3`，上限须计时验证），比较重叠路径的去重、质量与计算成本。**不能只是保留 3 条几乎相同的路径**。

**H2 可证伪标准**：若 GT 正确路径既不在候选集合中，也不能在小 ROI 内恢复，则失败属于候选生成/前端信号，而非末端选点；不得继续调末端阈值掩盖。

### H3：显式终止状态优于“DP 找尽了再对末端做门控”

要求在路径搜索中同时建模 `ACTIVE_CRACK`、`WEAK_GAP`、`END_STOP`（吸收态）、`BACKGROUND/NO_CRACK`（候选为纹理/尚未发现裂纹）等合理状态。状态含义、合法转移、最小/最大 gap、终止证据都要可解释，终止点参与全路径优化而不是只在长路径生成后被动剪断。

允许裂纹弯曲、已有参考裂纹、可见长度回落；**不允许**采用随长度增加必然变大的先验或“超过某长度即确认”。对 `NO_CRACK` 的正确识别和 `UNKNOWN_TIP` 的诚实输出同等重要。

**H3 可证伪标准**：与相同候选路径上的后验终端否决相比，联合停止状态必须减少错误长尾，且不能通过大量取消 GT 正确的已确认尖端来换取结果。

### H4：重定位应该从“首次持续证据分歧区段”启动，而非从错误长尾末端启动

沿候选路径定位最早出现多通道持续冲突的位置，区分弱纹理/短间隙/可疑分叉/真正终止；对这一局部 ROI 进行少量多分支重搜索。必须记录 `first_divergence_s`、`old_tip_s`、`new_tip_s`、搜索中心和 GT 是否处于实际搜索窗口内。

**H4 可证伪标准**：若初始路径已偏离真实尖端数百像素，仅围绕原末端搜索不应被评为“已修复”；要证明修复真正从首个分叉附近重新找回图像支持。

### H5：亚像素 Hessian 适合最后测量，不是物理裂纹真实性证明

Steger/Hessian 用于验证候选细线形态、局部中心与宽度，并在路径分支与真实末端已可信后提高中心坐标。**非裂纹划痕同样可能是好的脊线**；不能把亚像素精度等同物理尖端准确率。

**H5 可证伪标准**：独立合成细线中心误差下降，但真实图裂纹/背景判别没有改善时，报告“定位模块有效、真实性模块未证明”，不得用亚像素结果包装整体成功。

## 3. 实现前必须完成的“根因归位实验”（强制）

对 DEV-4 中每个已标注失败帧，构建如下六种输入对照，**逐环节判断失效点**：

1. `original_DP`：冻结基线输出完整路径与尖端。
2. `GT_path_oracle_evidence`：仅在评测框架中**使用人工 GT 中心线作为路径输入**，检查 Hessian/横截面/参考差异是否能正确识别真实线段；**Oracle 禁止进入生产算法，也不得算作模型输出成绩**。
3. `GT_path_oracle_endpoint`：使用正确中心线但让端点机制独立定位，评价变化点/停止状态本身的误差。
4. `GT_seed_oracle`：仅在诊断中提供正确起始位置，测试弱裂纹是否卡在 seed。
5. `K_candidate_oracle_recall`：检查正确路径是否在 K 条候选内；如果不在，末端优化无法从根本解决。
6. `temporal_fresh_vs_closed_loop`：从当前帧独立初始化 vs 从完整连续帧运行，判断历史是否把假路径重复强化。

每种对照都输出可复现的 JSONL，不允许将 GT 引导的 Oracle 路线与实际部署算法混在同一精度表中。

**必须回答**：错误第一次发生于配准、根部/seed、候选 DP、特征识别、路径竞争、终止状态、局部恢复还是历史反馈？给每个失败帧一个有证据支持的最早失效环节；证据不够写 `unknown`。

## 4. 新实验分支的最小工程实现

### 4.1 原有 DP 保留为稳定回退

- 保持旧接口和 `flags=0`、`flags=3572` 等原有行为数值兼容；不能静默打开新模型。
- 采用命名清晰的新实验开关：`EVIDENCE_ONLY`、`LLR_BG`、`MULTIPATH_K`、`JOINT_STOP`、`DIVERGENCE_RESEARCH`、`SUBPIXEL_FINAL`、`SAFE_TEMPORAL`；具体 bit 位须根据现有头文件空闲位分配，禁止冲突。
- 函数边界分离：`ComputeLocalEvidence()`、`BuildCandidateGraph()`、`SearchKPathsWithStop()`、`LocateFirstDivergence()`、`RefineCandidateTip()`、`CommitTemporalEvidence()`（建议命名，实际按工程风格实现）。
- 若已存在 Hessian/变化点/末端局部重定位，请**审查并复用可验证的代码**，重点确认其是在 DP 后审计还是参与搜索决策；不能盲目重复新造相同模块。

### 4.2 竞争证据：必须包含背景负例与证据不可用状态

- 按实际图像建立局部对照：裂纹候选中心、法向两侧背景、参考帧对应位置、同 ROI 的非裂纹负例、局部噪声尺度。
- 尽量区分 `line_like_now`、`new_or_extended_relative_to_reference`、`background_likeness`、`photometric_unreliable`；参考已有裂纹必须有专门分支，不能因为无新增差异就否决已有裂纹。
- Hessian/黑帽相关性必须通过统计分析；尝试剔除重复特征、特征消融，防止重复计数。
- 为弱信号/饱和/离焦设置 `evidence_unavailable`，不能将“无可用信号”强行判为“确定无裂纹”。
- 选择统一参数，必要时仅根据**可测的图像噪声和对比度**自适应，不允许依据 DEV 组别/文件名硬编码。

### 4.3 有界 K 候选与联合终止

- 对照 `K=1,2,3`，候选必须做几何去重；终止状态与 `NO_CRACK` 参与分数竞争；记录分数差、次优路径与终止位置。
- 短间隙模式应有明确最大长度和惩罚，但不一律判物理尖端；支持弯曲与短时可见长度回退。
- 路径成本不能因持续加和而偏向无限延长：必须报告长度归一化/终止竞争如何消除纯累积得分的长尾偏置，并用纯背景与长真裂纹合成反例验证。
- 路径必须连接可信根部；未知根部、配准不确定时可给候选但不能确认完整像素长度。
- 支持 `NO_CRACK`、`PATH_SUPPORTED_TIP_UNCERTAIN`、`TIP_CONFIRMED`、`REGISTRATION_UNCERTAIN`、`IMAGE_EVIDENCE_UNAVAILABLE` 等有明确含义的状态；未确认坐标不能冒充已确认尖端。

### 4.4 分歧点恢复，而非只修最后一点

- 沿候选路径按弧长计算各通道证据，找到**最早持续分歧**并记录；这是重搜索中心的候选，不自动称为真实尖端。
- 仅对该局部小 ROI 做有界候选恢复，设置最大 ROI、总分支数、循环次数和毫秒预算；失败时返回不确定，不拼出长尾。
- 评测需输出：初始 DP 与 GT 的首次偏离位置、`first_divergence`、局部搜索是否覆盖 GT、候选恢复率、恢复后端点误差、错误恢复率。

### 4.5 亚像素只用于可信中心线的最终细化

- 保留旧版像素弧长作为对照，并另报亚像素折线弧长；坐标系、取整、插值、点序和 path copying 需明确且一致。
- 对曲率退化、无纹理、接近边界的样本不得输出虚假的亚像素置信度。
- Hessian/Steger 得到的良好线中心，**本身不能使 `TIP_CONFIRMED` 成立**。

### 4.6 时序可靠性与状态隔离

### 硬门槛（任意失败则不能作为发布候选）

- **独立 GT 验证**：没有独立真实裂纹尖端和中心线标注，不得给 `PRODUCTION_GO`；仅可判 `ENGINEERING_FEASIBLE` 或 `INCONCLUSIVE`。

- **真实错误长尾**：在标注的伪长尾样本中，要求错误确认/过度延伸量实际下降；被标记不确定计入“未给出测量”，不可算作定位正确。

### 分级结论（必须输出一个）

- `GO_FOR_RESEARCH_ONLY`：工程可运行、合成/内部证据有价值，但真实精度尚无 GT 或未达标。
