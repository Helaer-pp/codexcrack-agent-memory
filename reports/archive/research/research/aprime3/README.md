# A′3 failure-driven research

Production remains frozen A. This branch investigates candidate omissions and local reference comparability; it is not a production replacement.

Run from the CodexCrack root with `D:/ProgramData/anaconda3/python.exe -B`. All generated files go to `output/runs/aprime3_20261105_r01/` by default. Set `CRACK_AP3_RUN` to a fresh alphanumeric/underscore run ID before a new complete experiment. The sealed AP2 run is read-only regression evidence, not executable code.

- `candidate3.py`: old-pool preservation, unconfirmed tracking terminal, multiscale event peaks and bounded refinement.
- `reference3.py`: patch eligibility before budgets; same independent registration/photometry validation.
- `decision3.py`: guarded stop/continue research and comparable past-endpoint diagnostic history.
- `native3.py`, `src/CrackV4_ap3_observer.cpp`: isolated seed observation, unchanged A calculations.
- `generate3.py`: DEV image generation and separate evaluator labels. Never imported by inference.
- `infer3.py`, `real3.py`: runtime-only inference runners; no physical labels.
- `evaluate3.py`, `controls3.py`, `postprocess3.py`: offline evaluation, clearly outside runtime.
- `media3.py`: original pixels and coordinate overlays, not generated imagery.
- `report3.py`: report and local media portal.

`research_valid` means an independently selected research endpoint. `selected_output_valid` means the returned coordinate is valid under its source contract; it may be fallback A. `A_FALLBACK_NOT_VERIFIED` is not a newly verified crack. Coordinates are original-image double pixels. Projected length uses ordered anchor right normal, not path arc length or calibrated mm.

Reproduction commands, remaining limitations, hashes, video and CSV links are in the run's `reproduce.md` and `index.html`. A′3 full native 15Hz has not been established.
