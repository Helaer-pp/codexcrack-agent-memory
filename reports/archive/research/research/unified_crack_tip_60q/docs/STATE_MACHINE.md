# 状态与选择

当前观测候选通过 RAW、起源/当前参考/有证据历史关联、观测比例、端点材料上下文检查才成为可靠候选。无参考不构成否决；强当前结构和起源支持可以独立成立。实际末端来自最后一段原始观测像素；gap 只做连接，不得产生新的观测端点。

轨迹以当前路径采样签名和位置进行软匹配。距离只排序身份关联；不能拒绝已验证新分支。主身份通过证据优势切换滞回，但正式选择独立取所有可靠分支原图 x 最大者。相同 x、不同 y 且证据不分胜负时 null。多轨迹关闭时，仅保留起源/RAW 最强一轨；因此该消融明确损失分支覆盖能力。

ACTIVE 没有当前可靠支持转 LOST；历史范围只影响搜索提示，不充当本帧尖端。8 帧内有独立当前支持可 REACQUIRING→ACTIVE；过期移除后独立重建。空帧不能复制 last_official。last_official 仅用于异常位移复查触发，允许后退和任意大跳跃。复查 RAW 法向截线、当前观测比例、边界和参考状态；证据足够同帧通过。不输出 MOTION_REJECTED。

初始工作带围绕缺口候选或不确定几何区。每224列结合独立结构 scout 调整中心/宽度、保留远处独立通道，无支持时扩宽回退；历史提示仍需当前候选验证。ROI扩张、RAW/骨架/段/边/根/路线/候选/轨迹/复查预算有显式计数。任何未完成使正式 null，即便部分候选已验证。参考配准预算不足只降级相应通道，强 RAW 可继续。

接口的当前图、固定图、实际前一帧和几何与合法状态以外，无样本名/组名/帧号/GT参数。候选与历史 ID 不用于数据集特化。
