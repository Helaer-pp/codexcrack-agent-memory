# CT3 短裂纹与可见末端复核（研究分支）

本分支按时序使用冻结 A、上一版断点恢复、以及局部复核三个步骤。前两步已有结果时直接使用。CrackGateProbe.dll 仅负责取得原生搜索证据；新增的短线段与末端规则在 adapt.py 中，属于 Python 研究实现。

对 no_seed、temporal_pending 或没有唯一重启点的情况，只在配准有效、缺口外侧明亮材料中查找短暗线。普通短段需要前序图像中的相同位置支持；强短段还可以通过 ±1 px 参考位置扰动检查，仅输出可靠后缀。对 terminal_strength 和 possible_forward_continuation，重新从可见段上游取方向并搜索末端；同时检查当前帧暗线、相对参考帧变化、前方材料和短时历史路径。已经获准的 A 和 V1 端点参与历史确认。完整长度沿用 A 的有效性；断点没有补线。没有未来帧、长度单调或试件名判断。

验证时在项目根目录编译 CMake 目标 CrackGateProbe，再运行 `python -B research/gate_adapt/validate.py <新的run_id>`。生成含原图视频、逐帧图、像素坐标及分段路径。回放逐一比对 V1 已交付结果。controls.py 注入已知被拒的路径以单测新增判断；另有 CT3 图像干扰对照。

CT3 已用于研发，真实尖端无独立标注，其他试件与整体实时性待验证。缺口新划痕与裂纹外观相同时仍可误检。生产发布版使用冻结 A。
