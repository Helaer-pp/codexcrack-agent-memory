# 事前固定的 ROI 单因素公式

输入仅为冻结整块安全ROI证据数组、当前真实P1/P2和全局配置。图像与参考P独立映射，缓存必须核对原BMP、P来源、原缓存SHA。所有组用同一函数；组名只属于外层清单与统计。

A = 原始安全候选矩形：xleft <= x < xr，upper+2 <= y < lower-1。原冻结C_FUSION_RAW完整路径引擎重跑，结果/节点/片段/边逐帧对照旧工件。上一轮其他证据模式不在本轮范围。

B中心为当前P的纵坐标均值，只是ORIGIN_GEOMETRY_UNVERIFIED，不认证物理缺口。令d为两点欧氏距离、h为安全高度，半宽H=min(0.4h,max(12,0.15d))；对安全掩膜与|y-center|<=H求交。x范围完全保留。

C初始半宽max(8,0.06d)，最大半宽max(Hmin,min(0.4h,0.30d))，推进步长8像素，最多3个走廊显示通道。若冻结的图像缺口假设在B带内，使用其x/y作为几何种子；否则用P中心线和安全左边界。缺口左方保留初始窄带，只作为种子初始化，不将黑缺口当可观测裂纹。种子在max(16,round(0.1d))列内从已有合格暗谷峰取至少2列支持的y簇，按距离几何中心、证据强度、y确定性选择，簇间隔max(4,0.03d)；无种子时保留几何中心假设。

每步在当前走廊内查询冻结融合响应的局部峰；至少2列支持的不同y簇允许并存。纵向漂移按冻结方向界限±0.45约束。支持离散度<=2px且距预测中心<半宽一半时，半宽缩0.8倍至下限；否则扩1.25倍至上限。缺失时扩宽且按当前斜率向前预测，只维持冻结图桥接距离clip(round(.02*安全宽度),8,24)，超过则终止该走廊。不无条件扩大为A。超过3簇记录GEOMETRY_BRANCH_CAP；每次扩/缩/终止逐列区间记录。通道ID是显示通道，不是已确认物理裂纹分支。

三个检测掩膜只作用于冻结run_mode的eligible变量，作用点位于峰选择之前。全分辨率E及相邻E比较仍来自安全ROI，不在mask边界补零。参考配准材料窗、noise/threshold、图桥接尺度、缺口排名先验、所有停止前后窗口均使用原安全ROI上下文。

每种结果额外记录原生输出和边界诊断；B/C候选或最后观测点距离搜索边界<=2px，或原停止方向前方24列±2px超安全几何时，公开状态标ROI_LIMITED且公开tip=null；原生候选及其停止分数不删除。A输出合同不改变，仅记录边界信息以保持逐帧parity。此几何拒绝不代表改进，不允许计为正确停止。

绘图C仅显示实际掩膜内像素，规则采样网格最多100x55，Z=原始灰度0..255，差分固定-40..40。所有mask、分支平面、原全分辨率灰度/差分的带SHA只读引用永久保留。绿色观测与橙色假设桥严格区分。显示可降采样，检测不可降采样。
