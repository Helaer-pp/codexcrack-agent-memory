# 方法、口径及限制

新代码只执行只读观察和离线比较。audit_plan.json在2026-11-12本轮评分前冻结，audit_plan_sha.json保存散列。2647全序列只复用旧候选清单，不声称重新全量计算；150输入AUDIT_OFF/ON各运行五模式。额外30输入按各组早/中/晚、未标注高短程分数/弱当前谷规则及固定237选出；不当阴性。111可见+9人工未知保持固定，算法UNCERTAIN另列。

原始候选GT-free文件为candidates/*/*/original_result.json.gz和lineage_observations.json.gz；完整短轨迹、原回溯和所有原始种子的额外诊断延伸先保存并哈希，之后独立evaluate.py读取LabelMe。生成函数签名不接受GT，注入测试明确失败。raw_seed_lineage.csv/hypothesis_lineage.csv/lineage_edges.csv不含GT评分；seed_gt_join.csv/hypothesis_gt_join.csv才加入人工距离/覆盖/误差。

观察使用Python profiler截获原Tracker.walk返回值，不修改原数学、参数或分支。NMS keeper按原排序和8/6邻域逐一复算，预算24；起源带重复按原y差7，原完整假设最多3。原短程观测数8、最长连续4、连接率0.5三条件按原短路顺序记录首次失败，不混为统一“过滤”。短程得分70密度+15截断当前暗谷+15回溯连接−2曲率全部分量留存。全量源/输出校验通过。

路径按≤1px弧长插值，只在观测连续段内连接，绝不连预测缺口。S1/S2距离3/5/10；S3短程可用要求≥8观测、至少8个GT样点被10px覆盖、精度≥0.8、x跨度≥7。S4覆盖/精度均≥0.8（10px），S5只用冻结原生末端，不根据GT挑停止列，联合要求同一个候选同时满足。另报起点邻近proxy，不冒充物理缺口身份。缺路径为N/A；空候选但GT可评估时记失败。无输出的可见帧保留分母。

TERMINAL未选中假设没有原生terminal计算，S4仍可比较完整探索轨迹，S5只允许原来选中的终止结果；不能据此将TERMINAL的受限端点上限与COMBINED不加说明混比。主结论固定COMBINED，所有其它模式完整保留。

E3固定原轨迹/分数/端点，以预注册双向5px覆盖、共同观测x、终点距离和分离连续段构图；主规则0.8/16列/0.5/10px，敏感性0.9/24列/0.75/5px，均禁止连续4列相距>10。连通分量代表为原最高排名，原top1不变，只重算独立竞争数与歧义；OFF先完整重现状态。给出两套结果，不选择最好者。所有改变同时记联合增损、公开错误、严重尾部、覆盖和不确定数。

E4没有新增模型：固定池重放原排名公式，直接参考项恰为0。逐列M2强度加分另列，不将它伪造为原路径评分。REF_ONLY/COMBINED不同候选池的结果不能当作纯参考权重消融，另给相同起点的下游血缘。

影子延伸覆盖所有原始seed（两个原M2设置，重复调用缓存），每次仍由原walk运行至原ROI/gap停止；没有生成新种子或改变阈值。其存在性仅作NMS等价keeper/连接门损失诊断，不参与S3–S5。它既不是GT引导追踪，也不是新增算法准确率。

独立缺口身份、当前P点的物理语义和旧划痕身份没有充分真值；E5只核对原图、P范围、原回溯与独立元数据是否存在，不另造缺口检测器。所有自动连接代理均保持UNVERIFIED。r0/r3/r5/r10图像证据是样点邻域统计，不是检测上限或可见性真值。
