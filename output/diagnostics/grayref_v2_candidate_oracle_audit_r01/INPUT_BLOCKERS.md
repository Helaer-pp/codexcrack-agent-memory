# 输入核查与限制

无阻止G0继续执行的文件缺失。

- CT3独立原始跟踪TXT缺失，继续使用历史明确帧映射坐标CSV；不认证原点物理语义。
- 没有独立物理缺口/旧划痕身份标注、真实无裂纹阴性或新盲测；对应物理事实保持UNRESOLVED，FPR=N/A。
- V2旧JSON未保存短程逐列轨迹与NMS keeper，使用原源码只读profile观察和确定性血缘复算补齐。
- 原V2仅对TERMINAL选中路径计算停止候选；其他假设的TERMINAL原生停止端点为NOT_LOGGED，不伪造。
- M2参考加分在逐列像素选择中；短程假设排名公式没有直接参考项，固定轨迹排序干预预计为零。需实测验证，不能另造参考总分。
