# V5.10 裂纹检测 DLL · Windows x64

本 SDK 对应 V5.10 r02。运行时使用原生 C++17、OpenCV 4.4.0 与 Microsoft Visual C++ x64 运行库。默认处理模式为原图暗线和固定参考有符号差分联合推理。开启 `raw_only` 可运行同版本纯灰度对照。两种模式均从参考原图定位材料带与缺口。

## 接入现有工程

1. 在 Visual Studio 选择 **x64 / Release**。头文件搜索路径加入本包的 `include`，库搜索路径加入 `lib`。
2. 包含 `CrackV510.hpp`，链接 `CrackV510.lib` 与 `opencv_world440.lib`，将 `bin/CrackV510.dll` 和 `bin/opencv_world440.dll` 放在应用 EXE 旁。
3. 每个采集流持有一个 `CrackV510Detector`，首帧初始化一次。每次提供当前灰度图与软件跟踪出的对应点。动态库和头文件带版本号，旧 A 软件接入时需要重新编译链接。

```cpp
#include "CrackV510.hpp"

// 程序启动时设置。OpenCV 线程数是进程级设置。
Crack510SetNumThreads(4);
CrackV510Detector detector;
Crack510Config config{};
Crack510DefaultConfig(&config);
// 已标定时可设置 config.mm_per_pixel = 标定值。默认 0，长度单位 px。
detector.initialize(referenceGray, refP1, refP2, &config);
Crack510Result first = detector.referenceResult();

// 后续每帧执行。在同一对象上按顺序完成处理和读点。
Crack510Result result{};
auto tip = detector.getCrackTipPointCirculate(currentGray, curP1, curP2, &result);
if (result.status == CR510_VALID) {
    auto path = detector.rawPath();       // 原图坐标，从算法根点到尖端
    auto arcPx = result.path_length_px;  // 整条识别折线弧长
    auto axialPx = result.projected_length_px;
    auto elapsedMs = result.detector_ms;
}
```

输入为单通道 8 位原图，可传带行步长的内存，当前图与参考图尺寸须一致。两点取原图像素坐标，P1 位于 P2 上方，点距至少 20 px。参考图在初始化时复制。初始化与每次逐帧调用都从像素计算，无需 Python、既有推理结果或人工标注。

`status` 的三个值分别为无可用缺口（0）、找到缺口但未确认尖端（1）、有有效尖端（2）。无尖端时，C ABI 的端点及长度为 NaN，路径为空。C++ 便捷函数此时返回显示坐标 (0,0)，业务判断请读取状态。弧长包含被算法接受的中段桥接，`bridge_columns` 给出其列数。投影长度取当前点对中点至尖端在右法向上的分量。提供有效标定后 `path_length_mm` 为弧长乘以 mm/px。识别长度与工程物理裂纹测长的对应关系取决于试验标定和根点定义。

`referenceResult()` 只读缓存的首帧结果，`rawPath()` / `pathSegments()` 读取最近一次成功处理的帧。V5.10 发布一条逐列连续折线，桥接与前缀处在同一折线中。C ABI 调用方先设置结果 `struct_size`。错误通过负返回值和当前线程 `Crack510LastError()` 查询。调用失败时丢弃本次输出，同一实例的成功结果仍可读取。C++ 包装器抛出异常。独立序列可使用独立对象。

## 验证组C亮区复现

默认 `material_mode=0` 使用输入点对确定的安全搜索区域。复现当前验证组C试件时，传入原始跟踪点及已确认的材料窗口。模式 1 使用同一材料带与原点位，模式 2 启用亮区虚拟点；两种模式都在原跟踪点对的上游参考配准场上取样。模式 2 对参考图和当前图逐点检查 9×9 邻域，输出 `actual_reference` / `actual_current`。下列参数只对应本试件原图尺寸，窗口右下界不含。

```cpp
Crack510DefaultConfig(&config);
config.material_mode = 2;
config.reference_box = {2229, 2259, 2876, 2431};
config.fixed_band = {2229, 2274, 2876, 2429};
config.fixed_floor = 180.15;
config.virtual_points[0] = {2248, 2278};
config.virtual_points[1] = {2263, 2423};
```

## 编译与运行示例

包内有 OpenCV 头文件、导入库、运行库及许可证。可直接运行 `bin/CrackV510Example.exe`，或在解压后的 SDK 根目录重新编译示例。

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -T v142
cmake --build build --config Release
.\bin\CrackV510Example.exe "参考.bmp" "当前.bmp" refX1 refY1 refX2 refY2 curX1 curY1 curX2 curY2
```

将最后八项替换为参考、当前两组实测数值。示例支持中文路径并输出状态、尖端、弧长和投影长度。逐组对照结果见 `verification/REPORT.md`，文件摘要见 `SHA256.txt`。
