# 从缺口沿原图灰度暗线追踪裂纹 · V2 r02

本轮共1633帧，GROUP_A551和三点弯520用于开发。冻结r02的源码、离线评价器、开发输出后，验证组C562只执行一次固定版本回归。各组标注只在本组预测封存后比较，未训练模型。验证组C此前已曝光，本次数据来自上一轮保存的原分辨率RAW、图像几何和参考证据缓存。每帧读取前核对数值文件SHA。上一轮严格隔离偏差已有记录，此处比较的是历史回归成绩。

联合指标要求尖端距离≤10px，并且在10px匹配容差下标注路径覆盖率、预测路径精度均≥80%。空输出保留在可见帧分母。GROUP_A达到原定三项数值门槛，三点弯差1个命中，验证组C差8个命中，整体验收未通过。全序列有效输出表示算法给出坐标。真实无裂纹负例的误报率仍未知。

每帧根据参考缺口位置和实际P点定位当前图中的厚暗缺口，在原灰度图上比较多尺度上下侧材料亮度与线中心灰度。算法从缺口边界出发，在20列的前探窗口内比较弯曲路径，逐段提交观测。当当前暗线支持不足时停止。差分只在对应参考可信且原图暗谷已达标的像素上小幅影响路径排序。该实现每帧独立选取一条向右路径。最多跨很短的弱观测段，图中绿色只连接相邻观测列。这一限制也使它容易沿错误缺口唇缘出发，或在远端纹理上延伸。

开发首轮（同目录层级 r01）仅从厚缺口最前端出发，GROUP_A16/19、三点弯0/15，后者有12个>100px误差。r02在首条路径很短时，还从同一缺口的上、下两侧测试起点，比较有原图支持的前伸范围。调整前已看过开发评价，属于开发反馈。三点弯端点命中改善，但第215帧显示前段沿上唇，人工线沿下唇，最后才汇合，端点误差2.08px而路径覆盖仅57%。GROUP_A第165帧的定位误差1.25px，路径覆盖和精度均为100%。验证组C14个未命中帧预测x均大于标注x，第38帧覆盖100%但尖端偏离22.75px。验证组C不用于修改本轮规则。

开发组同帧关闭双差分，GROUP_A命中/联合仍16/16张，三点弯命中仍10张、联合由1张变为2张。因而本轮开发结果中，差分没有带来额外端点命中。测试含连接暗线、仅缺口和缺口前方分离暗线三例。所有1633张同坐标局部对比图已核验，三段视频按10fps编码并全帧解码。
