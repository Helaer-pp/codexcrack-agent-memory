# 冻结 A 软件集成

适用于 Windows x64、MSVC、OpenCV 4.4.0 Release。bin/CrackV4.dll 是已验证的冻结 A 原始二进制，SHA256 为 c23498fcc660469927f63244b8e98e39b1eb86d542ec9a7b069d61fcf813654b。

## Visual Studio 工程

1. 使用 x64 Release。将本包 include 和 D:\opencv-4.4.0\build\include 加入 C/C++ 附加包含目录。本包 include 优先于旧 SDK 的同名头文件。替换旧头文件后重新生成调用方。
2. 链接本包 lib/CrackV4.lib 和现有 OpenCV 4.4.0 的 opencv_world440.lib。CrackV4.lib 按所附原始 DLL 实际导出的 19 个函数生成。
3. 把 bin/CrackV4.dll 和 bin/opencv_world440.dll 放在软件 exe 同一目录。所附 OpenCV DLL 已与 D:\opencv-4.4.0 的 x64/vc15/bin 文件逐字节哈希核对。目标机需要 x64 VC++ 运行库。每个进程首次初始化前安排好 OpenCV 全局线程配置，包内适配器首次初始化会将线程数设为 4。

## 对接现有逐帧回调

```cpp
#include "CrackV4.hpp"

// 定义在采集类内，整个试验共用该成员。
CrackV4Detector m_crackDetector;
```

以下代码放在该类的逐帧成员函数中。picNum 从 1 开始，gray 为当帧原始 CV_8UC1 图像，p1、p2 为当帧同一对标记点的原图坐标。参考图已知无裂纹可取 Clean，已知有初始裂纹可取 Cracked，情况未知可取 Auto。ratio 为本组标定值，单位 mm/pixel。

```cpp
CrackV4Result r{};
if (picNum == 1) {
    m_crackDetector.initialize(gray, p1, p2, referenceMode, ratio);
    r = m_crackDetector.referenceResult();
} else {
    m_crackDetector.getCrackTipPointCirculate(gray, p1, p2, &r);
}
const double tipX = r.tip_confirmed ? r.tip.x : 0.0;
const double tipY = r.tip_confirmed ? r.tip.y : 0.0;
const double lengthMm = r.length_confirmed ? r.length_mm : 0.0;
const double elapsedMs = r.detector_ms;
```

参考帧初始化后直接读取 referenceResult()。从第二帧起，按采集顺序对每张变形图调用一次 getCrackTipPointCirculate()。P1 在上、P2 在下，保持两个标记点的物理身份与顺序。输入完整灰度图和相应的原图坐标。一个序列一个检测器，每个新试件重新 initialize。初始化失败时结束该序列或重新初始化，本帧异常时记录错误并清除当帧显示。

tip_confirmed 和 length_confirmed 要分别保存。两者可能取不同值，显示层可以用 0 显示无效值。length_mm 是完整裂纹路径弧长乘以传入的标定比例。软件若另有“尖端到 P1/P2 中点”的距离指标，应单独命名。计算该距离前先检查尖端有效性。绘制正式裂纹时先检查对应的有效标志，再调用 rawPath() 读取 double 原图坐标。resultV2() 提供当帧停止原因和更多状态。

## 配置与验证

本包的 CrackV4.hpp 保留 initialize、referenceResult、getCrackTipPointCirculate、resultV2 等原有调用形式。initialize 使用 CrackV4CreateExtended，flags=3572，refine_anchor_motion=true，decision_policy=CV4_SHADOW，terminal_validation=1。直接使用 C 接口的项目按此组合创建，在第一次 Process 前调用 CrackV4SetOptionsV2。普通 CrackV4Create 和旧头文件走默认配置，软件中请使用包内头文件。

example/main.cpp 为可编译示例。在包目录运行以下命令可用本机 OpenCV SDK 编译。

```powershell
cmake -S . -B build -A x64 -T v142 -DOPENCV440_SDK=D:/opencv-4.4.0/build
cmake --build build --config Release
```

示例命令行依次传入参考模式（0/1/2）、比例，以及按时间排序的每帧“图像路径 P1x P1y P2x P2y”。输出列依次是帧索引、尖端有效、完整长度有效、尖端 x/y、弧长 px、弧长 mm、检测耗时 ms、路径点数和各点的 x/y。

本次已用包内头文件、导入库和 DLL 编译运行示例，并将六组各 3 帧与封存输出对照。18 帧的有效标志、有效尖端、有效弧长和逐点 double 路径一致。集成实测记录见 verification.json。
