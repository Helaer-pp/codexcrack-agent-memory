## 1. 核心技术决定：V1 规则现在冻结

### 1.1 冻结源码与身份

`paired_p1p2_roi_V1_FROZEN.py` 的 SHA-256 必须等于：

```
2e2e5ebef80ab33e486c561b6dec09ee15d23033020cc1886a7de24c7ce2baf6
```

开始时重新计算并记录哈希。源码只读，拷贝也应 byte-for-byte 相同。严禁：

- 修改暗谷评分、滤波、参考差分、ROI 规则、起点、路径罚分、停止规则或灰度阈值；
- 给 GROUP_A、CT2、开发组H、CT3、验证组C、三点弯或任何名称设置不同参数/阈值；
- 使用人工 GT、已知尖端位置、标注路径、未来帧决定本帧 ROI 或选线；
- 在 Python 与 C++ 之间无证据地“优化”计算步骤，导致算法身份改变；
- 将所有失败转为 `fallback` 或在实验中删除无法给出尖端的帧，使指标虚高；
- 用本图成功的 `(2423,2344)` 作为别的组的新起点、范围或隐藏对齐锚点。

允许改变的**输入维度**只有：参考图、当前变形帧、与该帧对应的参考/当前 P1/P2、输出路径、离线 GT 评价文件；算法参数全部固定。参考图源或图像尺寸不兼容必须显式报错，不能静默拉伸或对齐到 GT。

### 1.2 冻结 V1 几何与数值

参数以代码为权威；下列是核验清单，不能只照抄表而略过其他硬编码规则。

| 模块 | 原样冻结条件 |
|---|---|
| ROI 左界 | `xleft = ceil(max(P1_cur.x, P2_cur.x))` |
| ROI 上下界 | `upper=ceil(P1_cur.y)`，`lower=floor(P2_cur.y)`，且 P1 为上侧；严格保留上下边界 |
| ROI 右界 | 原有灰度行带启发式，`RIGHT_EDGE_X=None`（自动）；异常要记为 ROI 错误 |
| 初始 x | `xstart=xleft+6`，不是从标注路径自动选点 |
| 初始化 | 单列联合暗线证据×基准点中位高斯先验选择起点；固定先验 12 px 与 ROI 高度比例 0.23 |
| 当前图 | Gaussian `σ=0.7`；两侧 offset `6/9/12` 的最大暗谷对比 |
| 参考补偿 | 当前 P1/P2 相对参考 P1/P2 的平移沿 y 比例插值，`cv2.remap` 到当前坐标 |
| 新增变暗 | `newdark = reference_aligned_smoothed - current_smoothed` |
| 有效材料 | 两侧距中心10px材料灰度的较小值 `>135` 且在 ROI 内 |
| 联合分数 | `sqrt(max(valley,0)*max(newdark,0))`，比较必须**分别**满足 `valley>=T` 与 `newdark>=T` |
| 仅当前 | 不使用新增变暗，满足 `valley>=T` 的对照 |
| 阈值 | 冻结同时跑 `T=8/10/12`，默认结果展示 T=10，不能根据 GT 选择每帧最优 T |
| 曲线搜索 | 每列在预测位置上下 ±7px 内寻找观测，中心偏差罚 `0.55*abs(y-ypred)` |
| 方向估计 | 最近12个已观测点，至少5点回归，斜率夹在 ±0.20 |
| 断续/终止 | 连续未通过证据 `gap>20` 后停止，尖端是**最后一个通过证据的像素**，不是末次访问像素 |
| P 点追踪回退 | 未提供当前 P1/P2 时使用原 NCC 模板 29px 半径/搜索25px/NCC≥0.80；点失败要报错，**不能回退到猜测位置** |

**重要：** 上述算法目前只支持裂纹总体向右生长、参考/当前尺寸一致、P1 在上 P2 在下，且尖端保持在两个 P 点的严格 y 区间内的场景。不能为了通用性悄悄修改这些假设；若其他组不满足，应作为 V1 失败证据报告。其参考位移补偿只是两点线性插值，不可对外宣称已完成严格的两侧材料运动配准。

### 1.3 必须诚实标注的输出状态

- V1 `tip` 为**暂定观测候选端点**，缺少独立主裂纹身份认证和尖端确认，不等于生产 `confirmed/observed`。
- 无法完成的帧输出 null/失败状态和原因，保留分母，不得填 GT 或冒称 0 px 误差。
- `T=8/10/12` 属于预设消融，不允许测试后在每一组/帧中选命中 GT 的最优值作为在线算法。
- 若当前 P1/P2 或参考不可用，输出 `POINT_INVALID`、`REF_INVALID` 等可审计错误，不允许改成无证据的预测尖端。

## 3. 开发执行次序：先跑完，再谈移植与改进

### A. 启动、冻结与回归

1. 计算/保护 V1 SHA，检查已封存的生产 A/DLL 不被覆盖。
2. 用用户已有的 5120×5120 参考 `1 (1).bmp` 与当前 `3 (175).bmp` 回归：联合 `T=8,10,12` 应为 `(2424,2344)/(2423,2344)/(2418,2345)`；单当前 `T=10` 为 `(2285,2307)`。这些是已探索过的图像，**仅用于回归一致性，不算跨试件准确率**。
3. 记录 P 点来源、图片哈希、脚本 SHA、OpenCV/NumPy/SciPy 版本、端到端运行时；若环境变化造成像素差异必须溯源，不得重写 Golden 值。

### B. 全开发组 Python V1 端到端回放（不得因单组失败提前停止）

1. 优先直接使用已交付的 `batch_validate_V1.py` 或在此基础上加输入 adapter；不许调用它去改变 V1 源码。
2. 四组完整帧都要跑。每帧保存 `joint/current` × `T=8/10/12` 的暂定尖端、坐标、是否给出结果、ROI、点来源、失败原因、逐列轨迹、可见路径及时间。
3. 每组 20 个既有选帧生成质量可读的 overlay 联系图/HTML；特别要有 CT2/395、开发组H/78、GROUP_A/504、CT3/65。对以上哨兵不能强迫其成功，但必须记录错因。
4. 允许时间超过原定 50ms；首先得到实用可靠的完整输出。仍需原始计算时间、I/O、渲染分别计时以便后续 C++ 优化，不隐瞒高成本。
5. 一次运行出全套结果，不用每遇失败就回调阈值；如果需要调整，**另起研究版本 V2**，保留 V1 全量结果并获得用户批准。

### C. C++17/OpenCV 版本实现（Shadow，不替换生产）

1. 编写 `P1P2GrayRefV1` 模块，暴露 `initializeReference(reference, P1r, P2r)`、`process(current, P1c, P2c)` 或与现有 API 对接；每帧清晰传入点和引用身份。相同算法的批量文件包装层可另写。
2. **逐步镜像 V1 的数学和边界行为**，尤其包括：`cv2.remap` 的采样方向/边界处理、参考的 P1/P2 y 线性位移插值、ROI 边界取整、`np.roll` 位移操作、`scipy.ndimage.gaussian_filter` 的核与边界行为、联合 score、暗谷判定、并列极值顺序、像素整数选择、轨迹拟合、`gap>20` 的停止逻辑。
3. 不能使用 C++ 现有 A/R05G 的另一套评分替代 V1，不能因 50ms 预算截断、因其他组失败而单独改参数。
4. 可做提前缓存/分块/向量化，但**先实现严格 parity 模式**。为每帧输出 Python 与 C++ 同字段 trace，并报告差异：P 点、ROI、曲线前50点/最后50点、任意首次偏离、端点差(px)、候选个数、失败状态。
5. 预期不同库的浮点与核边界可能产生小偏差，不要求无理由承诺 bitwise identical。交付**实际测得**一致帧比例、端点差的 P50/P95/max、首次差异原因；较大差异逐案查明。
6. 只有 parity 通过及实际准确性报告可接受后，才可讨论替换生产。原 A/历史 DLL/ABI 需保留；新版本必须独立命名、独立构建与回退，不污染已封存版本。

**只以 `VISIBLE` 真实人工标签为尖端误差分母**，不能用全部1565帧计算 GT 精度。标签在全帧推理/冻结之后读取，严禁参与推理。报告：

| 指标 | 明确定义 |

| 错误 >100/500px | 所有 VISIBLE GT 上的严重暂定端点错误数量，不将无输出计为 0 错误 |
| P50/P95/max | **仅有可比较端点**的误差分位数，注明实际 n |

## 4. 失败定位必须是可操作的

每个主要失败案例至少把问题归入以下类别并给出**第一处可观测证据**：

- `INPUT_OR_COORDINATE_ERROR`：参考/当前帧错配、P1/P2 坐标系或时序索引错误、分辨率不一致；
- `P1P2_TRACK_FAILURE`：NCC 分数低或对错纹理；
- `ROI_GEOMETRY_EXCLUSION`：真实尖端不在 P1/P2 y 范围内或右边界识别过早；
- `ORIGIN_WRONG_LOCK`：xstart 单列先验将首次中心选择到夹具边界/旧划痕；
- `REFERENCE_COMPENSATION_UNTRUSTWORTHY`：仅两点插值不能处理实际非均匀变形；
- `MATERIAL_GRAY_VETO`：`MIN_MATERIAL_GRAY=135` 过度排除有效裂纹区域；
- `CURRENT_VALLEY_MISSING`：局部当前灰度暗谷不足；
- `REFERENCE_DELTA_MISSING`：参考本就有裂纹、差分失效或配准错误；
- `PATH_JUMP_OR_OVEREXTEND`：追踪误入划痕/边缘，在真实尖端后继续延伸；
- `PREMATURE_GAP_STOP`：喷漆遮挡/短弱片段导致 `gap>20` 过早停止；
- `NOT_OBSERVABLE`：当前图像物理尖端不可见；
- `UNKNOWN`：证据不足，必须保存原始数组/轨迹供复核。

每一类至少给出计数、代表帧、像素/灰度证据。不得简单把所有错因写成“阈值问题”或“背景复杂”。对同一组正常/失败帧并列展示参考图和当前图 ROI、P 点、原图暗谷 `valley`、`newdark`、材料 mask、最终路径、停止位置；路径不能由人工标签重画冒充算法输出。
