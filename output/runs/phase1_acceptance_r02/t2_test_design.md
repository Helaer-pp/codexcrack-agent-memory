# T2 试验设计

T2-A 采用同一原始图像序列、同一当前点轨迹、同一候选 DLL 和同一配置；每个初始点变体独立创建检测器并完整按时间顺序回放。控制组为 `measured`。

初始点变体由每组原始间距 d 自适应构造：共同平移 ±5% d（x/y）、间距缩放 0.95/1.05、围绕中点旋转 ±2°、单独移动 P1/P2 ±5% d、组合平移+旋转。变体保持点序；先做有限性、图像内、最小间距检查，非法变体单独计数，不进入有效 P95 分母。

T2-A 的当前帧 P1/P2 对所有变体统一使用清单中的原始当前轨迹，隔离初始化差异。T2-B-real 需要不同初始点对应的真实外部追踪轨迹；工作区未提供，判定 BLOCKED。可选的统一变换轨迹只作为 `T2-B-synthetic`，不当作真实工作流验收。

窗口策略：每组使用确定性的连续前缀窗口，优先覆盖初始化、正常跟踪和 R01 已知确认/不确认区间；窗口长度和停止原因写入 `t2_summary.csv`。不按确认结果过滤帧。
