最新研究候选 V6.3 S2，软件集成发布 GrayDetectionV2 2.2.0.0。开发组H有两帧的尖端提前超过 100 px，旧暗线侧移专项仍有 22/30 个误报。[阶段报告](../evidence/v6_3/REPORT.md) · [失败复盘](../evidence/v6_3/FAILURES_AUDIT.md) · [各轮报告索引](../reports/INDEX.md)

| 路线 | 方法 | 可复用的实验结论 |
|---|---|---|
| R05F/G/H | 逐步暗线、方向横截面、候选终止与历史身份 | R05H 在旧六组协议中开发正式 Hit@10 为 7/76，曝光验证 4/35。错误历史首锁和提前停止都能延续。 |
| GrayRef V1/V2 | 当前灰度与固定参考联合，后续加入起源候选和局部配准 | 原 V1 的旧协议结果为 12/76 与 5/35，V2 COMBINED 为 4/76 与 4/35。严格筛选降低覆盖。 |
| 简化证据与 ROI 消融 | 固定证据，改变搜索域或候选保留方式 | 缩小 ROI 会改变候选竞争与连接。即使标注尖端在 ROI 内，部分路径仍可能被裁掉。 |
| UCTIP-60Q | 原灰度暗谷、独立双参考、图连接、多轨迹、逐段 ROI | A/B/C 正式 Hit@10 为 0/19、3/15、12/20，路径与尖端联合为 0/19、0/15、10/20。A 的 551 帧全部耗尽预算，B 的 93 次预算失败都触发了轨迹上限。冻结前误跑旧 A 检查读取了 C 的图像与点位，该轮严格隔离审计失败。 |
| 原灰度 r01 | 从厚暗缺口最前端单一起点追踪 | A 命中 16/19，B 命中 0/15，B 有 12 个误差超过 100 像素的正式输出。 |
| 原灰度 r02 | 首条路径短时尝试同一厚缺口的两侧起点 | A/B/C 正式 Hit@10 为 16/19、10/15、6/20，联合为 16/19、1/15、6/20。三组严重误差均为 0，整体仍不满足验收门。 |
