## 0. 不可变需求（先锁定，不得自行扩大范围）

1. **方向**：当前只考虑右向单侧裂纹，CT / 三点弯等试件统一以当前帧 P1/P2 基准线的右法向作为“正向”；允许裂纹弯曲和局部转向，但不开发双侧、多根源及向左独立追踪。
2. **最关键的测量对象**：**尖端 (x, y)**。所有实验的第一精度指标是同一可观察范围、同一真值定义下的尖端二维误差；不能以中心线弧长好看、曲线平滑或确认帧多代替它。
3. **路径**：保留并输出用于搜索/诊断的有序路径；它可以不完整，也可以与最终尖端存在修正差异。必须显式记录路径有效性及与尖端的关系，不强制从真实根部连续连接到尖端。
4. **根部**：保留现有估计的兼容能力，能定位则输出；不能定位则 `root_valid=false`。根部识别不是本轮核心研究，也不能成为新的尖端否决条件。
5. **长度**：新增 `horizontal_length_px`，定义为尖端相对于当前帧 P1/P2 基准线的右向投影，不是旧 V2 的 root-to-tip 中心线弧长；无标定不得输出毫米值。
6. **ROI**：必须完全由统一的几何和图像规则自动生成并动态更新。不得按试件名称、文件路径、已知帧号、经验固定 ROI、已知 GT 选择参数或边界。
7. **统一自适应**：允许拥有少量全局冻结的无量纲常数、尺度倍率及资源上限，但不得针对某一试件、材料或验证组设置阈值。图像自适应函数必须可解释、可复现、可消融，参数只由参考/当前图像、P1/P2 和先前合法状态计算。
8. **停止与确认彻底解耦**：`evidence_ended`、`direction_ambiguous`、tile 到边界或候选耗尽仅表示搜索事件，均**不能单独证明物理尖端**；反过来，原 DP 未完整找到路径，也不得在存在充分独立局部证据时一概禁止尖端候选。
9. **不得强行输出**：不可辨识/多个同样合理的候选应报告 `AMBIGUOUS` 或 `NOT_OBSERVABLE`；不过不得通过大规模撤销原 A 正确正例来假造精度提升。
10. **保留相位/物理边界**：目标是“当前图像可见、可辨识的裂纹端点”。没有独立物理标注与同步载荷时，已形成材料裂纹物理尖端精度 = `N/A`，相位 = `PHASE_UNKNOWN`。

**本轮明确不做**：Frangi 全量替代、A∧D+G 硬门控、强制长度单调、复杂多路径全局重搜索、双侧裂纹、人工根部标注驱动算法、针对已曝光三点弯/排除组X问题帧拟合专用阈值。

## 3. 新算法测量合同：尖端唯一主目标，路径和根部分离

### 3.1 坐标和投影长度必须一开始固定

输入每帧 P1、P2（原图像素坐标）。以原图像素表示：

\[
O=(P_1+P_2)/2,\quad v=P_2-P_1,\quad
u=(v_y,-v_x)/\|v\|.
\]

在约定 P1 位于 P2 上方的输入下，`u` 应指向画面右侧；不同输入顺序时必须按已冻结的点身份/方向合同核对并显式处理，**不得根据当前算法输出选择正负号**。右向水平投影：

\[
L_{\mathrm{horizontal,px}}=(T-O)\cdot u.
\]

其中 T 是经验证有效的当前帧尖端坐标。`horizontal_length_px` **不能**直接使用旧 V2 的弧长字段，也不能因为 `root_valid=false` 而返回 0；负值与零值的语义分别声明。无有效尖端时长度输出 `null/NaN` + `valid=false`，API 兼容所需旧接口零占位必须保留独立 validity，绝不可把无结果计作真实零长度。

同时保留：

- `path_points`：当前可支持的候选路径/可信子段，原图 double 坐标、有序、可为空；
- `path_valid`/`path_role`：`A_CANDIDATE` / `TIP_CONSISTENT_SUBPATH` / `DIAGNOSTIC_ONLY` 等；
- `root_xy`/`root_valid`：可选；不能拿 `root_valid` 决定 `tip_valid`；
- `legacy_arc_length_px`：如保留，必须注明旧的根部至尖端弧长，不与投影长度混名；
- `tip_status`：`CONFIRMED` / `AMBIGUOUS` / `NOT_OBSERVABLE` / `NO_TIP_EVIDENCE` / `INVALID_INPUT`，并输出可解释 reason；
- `tip_candidate_count`、`tip_evidence`、`roi_status`、`photometry_status`、`registration_status` 和版本 hash；
- 有效尖端但无完整路径的状态必须**可表达、可测试并能序列化**。

建议**新增研究 V3 接口或独立 JSON/CSV 输出**；既有 A 的 `GetResultV2`/`CopyPath` 不动。

### 3.2 定位与确认的职责区分

- `Search`：产生 DP 主路径、可选局部尾部候选及停止原因；即使原 DP 停止也只意味着搜索终止。
- `TipLocalization`：在 DP 末端、已知歧义点及其有限前/后范围内，独立比较尖端位置；必须支持“原 DP 太长”与“原 DP 太短”两种方向，不得只截短。
- `TipValidation`：通过预先冻结的观测证据决定尖端是否可确认；**不从 `evidence_ended` 直接推出 CONFIRMED**。
- `Measurement`：只从 `tip_valid` 和 P1/P2 计算投影长度；路径和 root 是辅助信息，不构成必需条件。
- `TemporalEvidence`：可使用过去已确认信息辅助消歧，但不能假设物理裂纹可见长度逐帧单调；不同加载相位的暗线闭合不可强行平滑。

不得用 `A.confirmed && DG.confirmed`、`shadow_tip`、`root_supported`、路径完整性或“无参考差分=无裂纹”单项硬门控。

## 4. 阶段 C0：统一自适应 ROI（优先交付可运行版本）

### 4.1 不需要精确根部，但必须明确初始搜索域

1. 使用 P1/P2 的中点 O、右向单位向量 u 和法向、标距 `d=||P2-P1||`，建立**材料相对坐标下的初始搜索带**。
2. ROI 初始高度、宽度由 `d`、图像边界、材料掩膜及从参考/当前图像推断的候选暗线特征共同确定；所有倍率、最小/最大尺度和安全边距是全局冻结的同一策略。
3. **不强制寻找物理根部**：可从基准线右侧合理范围寻找候选起始暗线，允许存在短暂根部缺失；不能因此允许任意远处背景线条被确认为裂纹，必须对搜索证据来源和空间连通性作审计。
4. 逐 tile／逐层动态扩展 ROI，支持中等曲率、上/下偏移、长度增长；即使路径向右，局部切向可弯曲。
5. ROI 在潜在尖端附近必须额外保留前方审计余量：**不允许因为 ROI 右边界恰好到达就断言尖端**；预算/材料边界内无法继续审计应 `ROI_LIMITED`／`UNKNOWN`。
6. 自动记录 ROI 在原图、当前帧和参考材料坐标中的四角、尺度、扩展原因、边界碰撞及降采样率。

必须做两个反事实测试：增大前方/上下安全边距后，如果尖端变化显著，则原结果不能标称“独立于 ROI”；在保留相同图像证据和算力预算下，比较固定/动态 ROI 的独立影响。

### 4.2 禁止的 ROI 伪自适应

严禁：

```python
if "ct2" in path: roi = ...
if frame_id == 473: roi = ...
if crack_length > known_gt: stop = True
```

不能靠 ROI 裁掉长尾获得表观精度提升，更不能将按组修改降采样步长和 ROI 长度的整体效应宣称为“ROI 单独改善”。

## 5. 阶段 C1：统一尺度／噪声／光度自适应（本轮最重要的普适性机制）

### 5.1 尺度：从实际图像推断，不按试件命名

- 将 P1/P2 标距视为宏观搜索几何尺度，但**不能假设所有试件的裂纹线宽与标距严格成比例**；
- 候选裂纹局部宽度可从跨线灰度剖面、梯度边缘间距或 bounded 多尺度响应估计，并在图像实际采样率内生成全局统一的尺度集；
- 把绝对像素参数（如 5/9/13 px 特征核、固定像素间隙、tile 步长、法向偏位容忍）整理成**从 `d`、估计线宽和分辨率推导的相对量**；
- 多尺度上限、候选数量、计算预算必须固定；输出每帧最终选用尺度及失败状态，不能默认对低分辨率或极弱纹理图像强行放大恢复不可见信息。

### 5.2 噪声：鲁棒背景估计与归一化证据

- 从参考/当前图像中符合材料掩膜、非饱和、非疑似裂纹条件的稳定背景区域估计局部噪声，如高通残差的 MAD/分位数；
- 区分弱纹理（背景真的平坦）与错误的零噪声估计；设有**全局推导的鲁棒下界与 `UNKNOWN_NOISE`** 处理；
- 在同一尺度和可比光度条件下构造有量纲记录的对比度及无量纲 SNR，例如 `contrast / max(estimated_noise, eps)`；`eps` 来自全局噪声／量化政策，绝不可每组人工改值；
- 对不同 bit-depth、反射、局部饱和和光照变化作显式测试，不能将 `8-bit` 的绝对阈值机械迁移到另一编码范围。

### 5.3 光度：必须完成可判定的合同，不允许“伪对齐”

- 明确先做几何配准，再在**独立于裂纹候选的稳定材料区域**估计参考与当前之间的亮度/对比度关系（如鲁棒仿射或分块局部光度模型）；
- 排除缺口、孔洞边缘、运动残影、高梯度饱和区域和疑似裂纹扩展区域对光度估计的污染；记录参与像素比例、残差、空间覆盖及拟合稳健性；
- 光度模型不可信时返回 `PHOTOMETRY_UNKNOWN`，其差分分支降级为 `UNKNOWN`，**不得把“差分无证据”当成尖端反证**；
- 继承 B4 已知的“光度有效性合同尚未完成”问题，先补单元测试后再允许端点证据使用。

### 5.4 证明是真正的统一规则，而不是外包参数调优

在 `adaptive_policy.yaml` 或等价源码中集中声明**所有全局常数**及推导公式，自动输出每帧最终参数到 `adaptive_params_per_frame.csv`，包含 `d`、线宽候选、噪声、光度残差、对比度尺度、阈值、ROI、采样率及选择依据。

**禁止**输入 specimen_id、材料名称、实验名称、已知 GT、路径标签、特定 frame_id 来产生参数；通过静态检查和同一张图像随机更名/换路径的**元数据不变性测试**证明。

- A 输出作为冻结基线和候选来源；
- C 候选可以包含 A 当前终点、主路径上若干局部变化点、前方有限范围内的延续端点及局部替代分支；
- 新方案能在 **A 未确认、路径不完整、根部缺失**时尝试局部尖端定位，但必须有足够的独立局部裂纹证据和空间来源约束，不得凭一条任意暗线伪造尖端；
- 尖端局部搜索要允许法向小偏移，记录 offset 而不把偏移后的灰度支持混同于原中心线支持；
- 不得只比较 2D 点离得近不近，需检查候选是否属于同一结构、是否跨越错误分叉/静态纹理。

**简化原则**：不要为追求完整路径准确性而重新实现一个重型全局 graph-search。研究阶段固定候选上限、有限前后窗口、共享已计算 tile，优先将计算资源用于尖端局部辨识。

### 6.2 显式比较三类相互竞争的假设

对每个候选区域至少形成：

- `H_STOP`: 在某位置结束；
- `H_CONTINUE`: 边缘后仍存在同一裂纹的可信延续；
- `H_FALSE_BRANCH`: 前一段延伸可能转入静态纹理／运动边缘／其他暗线。

这些是假设标签，不是正确分类；分数构建规则必须预注册、可逐项导出。允许 `UNKNOWN`，不得默认最短或最长、累计 gain 最大者正确。

### 6.3 独立尖端定位和确认必须解决“信息循环”

本轮必须说明：新 `TipLocalization` 比 A 的 `evidence_ended` 多使用了哪些**空间上独立、统计上有差异或未参与候选搜索的验证量**？

最低要求包括：

- **候选尖端前后证据差**，而非仅最后一个 tile 的 gain；
- **允许法向小偏位的暗谷/边缘剖面**，但要限制跑到邻近另一条伪线；
- **裂纹局部的形状与对比度可辨识性**，对弱化、断裂或闭合时返回不确定，而不是自动提前停止；
- **参考差分只在配准/光度有效时作为辅助**，并提供无差分和差分未知的消融；
- **候选延续/替代路径竞争证据**，避免原路径走偏以后只看尾部；
- **可信时序观测**，如使用历史必须覆盖候选末端邻域，不能只核对最前约 30 点；不同载荷相位不可强制长度单调。

如果证据不足以区分物理真实尖端，只返回 `AMBIGUOUS/NOT_OBSERVABLE`。**不要把诊断分数包装成未经校准的“99% 置信度”。**

### 6.4 不允许“靠拒绝正确正例改善 MAE”

对每个版本同时报告：所有已知端点正例中确认率、阴性误确认率、条件/配对 tip MAE、全部正例损失（包括未确认的惩罚/风险覆盖曲线）、>8 px 假长尾和提前停止、A 正确正例被撤销数。

失去 1 个原本准确的 A 正例不能因其没有纳入条件 MAE 而自动算成收益。新输出尖端不同于 A 时必须有**独立已知端点**证明是否更准；单看 A-C 位移不算精度。
