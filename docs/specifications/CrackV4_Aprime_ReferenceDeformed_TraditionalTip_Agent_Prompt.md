# CrackV4-A′：参考图 × 变形图联合证据与轻量尖端判决——Agent 研发任务书

> **交付类型：可执行开发任务（不是仅提出方案）**  
> **核心目标：** 在 CT、三点弯等**单侧、总体向图像右侧扩展**的疲劳裂纹图像中，只依赖**参考灰度图、当前变形灰度图、各自 P1/P2 和合法可用的少量历史状态**，使用**传统、确定性的图像算法**，在冻结 A 的 C++ DP 搜索基础上提高**真实可见尖端的二维定位准确性**，尤其降低错误长尾和过早停止。**同一套代码与统一自适应规则适用于所有试件，禁止按试件名称调参**。保留路径；根部可选且不作为尖端有效的必要条件；主要长度为相对当前 P1/P2 基准线的向右投影。
>
> **硬限制：禁止深度学习、神经网络、DIC、密集光流/位移场求解、大规模全图第二检测器以及试件专用人工参数。** 总算法使用 C++17 / OpenCV 4.4，生产目标 15 Hz（完整原生核心单帧预算 66.67 ms）；离线 Python 允许用于统计、图像分析及实验，但不能冒充生产性能。
>
> **最重要的工程约束：冻结生产 A 完全不变。** 不得修改、覆盖或重新发布其源码、DLL、ABI、参数、正式视频、历史输出或标准回放。新功能全部置于独立 `A_prime_reference_joint/` 研究工作区和新构建产物。若独立证据不足或新 TEST 未通过，结论必须为 `KEEP_A / A_PRIME_RESEARCH_ONLY`，不得强行上线。

## 0. 任务目标与既有结论（已曝光事实，不是新的独立验证结果）

用户最终需求明确为：**尖端坐标准确性最优先，路径保留，根部可选；当前只跟踪总体向右生长的单侧裂纹。** 不以完整弧长、精确根部、双向裂纹或多源检测为本轮目标。

过去的研究已经表明：

1. 冻结 A 的 DP 路径候选搜索具有价值。三点弯 519 张变形帧中 A 有 445 帧确认尖端；多组原生 A 在已有测试机器上通过核心 66.67 ms 预算。**输出覆盖率不等于物理准确率**。
2. 排除组X `num=473`：A 延伸 **22 个 tile**，在很远处才因末块支持点 1、`gain≈1.480953 < 4` 触发 `evidence_ended`；原生确认复用了主要针对**路径前缀**的时序支持，最后输出约 **1084 px** 的长路径。应区分“DP 搜索停止”与“尖端正确”。
3. 排除组X `num=51`：长路径中可产生很高的局部 gain，但最终因 `direction_ambiguous` 被拒绝。这表明**局部高分不代表真裂纹**。排除组X的实际物理尖端仍无独立 GT。
4. CT2 `num=6/18/84` 的不同配准对应约 4.6–5.3 px 的映射差异，并能改变 DP 采样与停止位置；排除组X上述关键帧不同映射的锚点中心差为零，**不能把所有异常归咎于配准**。
5. Frangi、D+G 硬融合曾大规模撤销 A 正确候选，不能重新使用 `A ∧ OtherDetector` 作为默认确认方法。
6. C_FULL 曾有 157 帧 A 正确（程序已知端点误差 ≤8 px）的输出被撤销、19 帧被改错；157 帧中均能在候选池中找到 ≤8 px 候选。这是**离线 GT oracle 的追因事实，不是在线可用的正确候选选择器**。
7. 在强假尾/真长匹配实验中，**当前图像及 P1/P2 完全相同、参考图不同、已知尖端不同**。任何只读当前图而不利用参考/历史信息的确定性算法，不能同时正确区分两种解释。
8. C2 在一次新受控 TEST 中修复 **20/27 个强假尾配对帧**，但损坏 2 帧本来准确的 55° 弯曲裂纹尖端（误差约 161/163 px）；DEV 也曾损坏 13 帧。它证明参考图可贡献信息，**却没有证明“参考纹理转折 = 尖端”可靠**。
9. C2 新 TEST 参考几何/光度验证约为 418/486、392/486，但六组真实试验同时验证通过**仅 2/3035**，归属 `SUPPORTED` 为 0，全部退回 A。真实试件中固定背景块布局及有效域/匹配条件缺乏普适性。真实六组没有独立物理尖端 GT。
10. C2 研究版 Python 不是实时生产实现；先前的 ROI 分离和候选保留可以复用思路，但不能直接把 Python 全链路装进 A 的原生核心。

**本轮研发问题不是“再找一种更强的线状滤波器”，而是：**

> 能否从**参考图与变形图的可信、局部、增量信息**中得到足够廉价的证据，区分真实新增裂纹与已有静态暗纹理，并将该证据与 A 的 DP 途中停止候选结合，在**不误伤已准确尖端**的前提下提高最终尖端精度？

**必须将两类误差分开：**
- **候选生成错误**：正确尖端附近根本没有候选；
- **候选选择/归属错误**：准确候选存在，但被错误拒绝，或静态纹理变化点被错误升格为尖端。

研究必须以可否证的证据为依据；不允许把排除组X 473 的视觉效果作为唯一成功标准。

## 1. 输入与输出合同

### 1.1 运行时合法输入

允许读取：
- 参考图 `I_ref`（当前试验对应的冻结参考帧）；
- 当前变形图 `I_cur`；
- 参考帧与当前帧的 P1/P2（须记录坐标及来源）；
- 冻结 A 已有的几何变换、DP 中间响应、tile、路径及尖端（仅用于新研究边车；不允许修改原 DLL 的内部行为）；
- 如果原生产实时过程合法持有，且有明确时间/相位语义的历史观测。**不能依赖未来帧、整段离线序列或 TEST 元数据作在线判断**。

禁止输入：`specimen_name` 对应阈值、DEV/TEST 标签、当前帧号对应异常名单、真实 GT、人工标注端点、已知历史失败帧的坐标、数据来源识别标签，以及 C2 离线 `oracle` 结果。路径和根部可以作为几何线索，但不是尖端确认的充分条件。

### 1.2 当前几何约束

- 试件限定为右向单侧扩展，允许 55°、75°、S 型、渐浅与大弯曲；不得默认裂纹沿水平直线。
- 初始搜索与动态 ROI 可以依据 P1/P2 几何、自适应信噪比和候选轨迹确定；不要重新开展复杂根部分类、多裂纹源或双向搜索。
- 所有坐标返回**原图坐标系**，记录所有缩放及几何映射，避免原图/ROI/配准坐标混淆。

长度合同：

\[
O=\frac{P_1+P_2}{2},\quad v=P_2-P_1,\quad u=\frac{(v_y,-v_x)}{\|v\|},\quad
L_{\mathrm{horizontal,px}}=(T-O)\cdot u.
\]

其中 `u` 应统一指向当前图像右方；如果 P1/P2 次序异常、间距无效或变换不可用，返回明确失败状态，**不能偷偷翻转方向或沿用上一组标定**。此投影不是从真实缺口根部开始的中心线弧长；未标定时不输出 mm。

## 3. 核心研究：从参考图 × 变形图获得哪些额外信息

先对**候选路径附近的细长带**而不是全图进行研究，所有统计使用原图像素尺度或严格记录的多尺度变换。当前图与参考图具有两种不同用途：当前图用于**找形态末端**，参考图用于**判别新增还是原有纹理**；必须先验证比较是否可信。

### M0. 自动生成的搜索 ROI 与尖端审核 ROI（基础合同）

- 使用 P1/P2 的间距、局部裂纹线宽估计、图像边界与 A 候选搜索轨迹创建自动 ROI；同一公式，不读试件标签。
- 搜索 ROI 可随路径扩展并围绕可能的曲率放宽，但**搜索域变大不能直接迫使审核采样步长变粗**。
- 每个尖端候选的审核窗口独立于搜索 ROI：在原图 1px 或经明确标定的固定局部采样尺度上，覆盖尖端前、后及法向相邻带；前方审核越界先进行一次局部扩展尝试，失败后返回 `AUDIT_OUT_OF_VIEW/UNKNOWN`。
- 独立测试：固定候选、固定原图窗口、固定噪声与线宽时，将搜索 ROI 放大 1.5 倍，端点证据的**逐数值计算**必须一致。另行测试重新搜索可能产生新候选，不把两个实验混为一谈。

### M1. 局部几何对齐：从两点刚体初值到可信的材料对应

**目标：不是求 DIC 位移场，而是让参考与当前图在候选周围能够逐像素公平比较。**

1. 以原生 A 的 P1/P2 及已知原生运动变换作为初值。保留与“P1/P2 纯刚体”之间的差异，作为诊断而非真值。
2. 在**不属于候选裂纹带**的材料背景中，用确定性的轻量特征选择选择可观察块：梯度/方差/饱和/纹理重复度、材料掩膜、距裂纹候选的距离、空间覆盖。不得依赖固定“24 块特定相对坐标”或从试件名称选择采样块。
3. 在有限的搜索半径内用小块 NCC、归一化梯度匹配、ORB/AKAZE 等**传统稀疏匹配**作为备选；必须报告各算法真实耗时和失败比例，选一套最简有效方案。禁止密集 DIC、光流场和整幅非刚性求解。对同一试验可在参考帧缓存特征。
4. 仅在有足够空间分布的独立材料匹配时，求小自由度的局部平移/旋转/仿射残差，使用鲁棒拟合及奇异/退化检查。不要让单个高相关贴片决定整个变换；不要把局部材质形变误当成刚体充分证明。
5. 采用**严格空间隔离的 FIT / HOLDOUT 背景块**：拟合变换用 FIT，检查残差、相关性与空间覆盖用 HOLDOUT。候选裂纹带及其外扩区域禁止进入训练/验证，避免利用要识别的裂纹本身为参考配准背书。
6. 最终输出 `ALIGN_SUPPORTED / ALIGN_UNKNOWN / ALIGN_CONTRADICTED`，并记录局部有效域（polygon/bbox）、残差分位数、匹配数、空间分布、变换大小和拒绝原因。
7. 配准仅对**被验证覆盖的局部材料区域**有效；不能因为远处一个块的相关性高，就宣布候选尖端位置可可信比较。

**必须实现独立反例：** 原始图配准正确但路径穿越静态纤维、孔洞边缘发生运动、0.5～5px 变换误差、局部非刚体变形、重复纹理、低纹理、强反光/饱和。验证 `UNKNOWN` 不会改写 A。

### M2. 光度归一化与噪声自适应：先建立可比性，后计算差分

- 对 M1 已验证的稳定材料块，用鲁棒灰度仿射关系（如 `I_cur≈a*I_ref+b`）或更简约的局部偏移拟合；记录模型选择原则、样本覆盖与留出残差。
- 对灰度饱和、局部镜面反光、曝光突变、遮挡、配准误差异常处标记不可比较；不得默认为平整无裂纹。
- 估计噪声时用不受候选裂纹/孔边/亮暗边缘污染的背景样本与鲁棒 MAD/分位数；保留噪声估计的样本数、空间覆盖和不确定性。
- 区分**暗线强度**与**新增暗线强度**，不得把 `I_ref-I_cur` 的符号和光度偏差一概视为裂纹。比较局部对比度、差分残差、背景噪声和参考纹理。
- 对真实材料低纹理/光照变化情况，允许选择更弱的仅灰度偏置校正、或返回 `PHOTO_UNKNOWN`；**不能通过降低可信度检查的门槛制造虚假支持率**。
- 校验：光照整体偏移、整体增益、局部梯度、反光斑、非裂纹静态边缘、参考图已有裂纹、16位→8位量化等工况。

### M3. 沿 A 候选路径的参考—当前增量证据（核心机制研究）

对 A 主路径与其**少量**备选停止点，按材料坐标在路径弧长 `s` 上记录以下分段证据；必要时允许局部法向 ±r 的小范围重定位，但要明确 `r` 来源于统一尺度/噪声估计，不能按试件设定：

| 证据 | 从图像回答的问题 | 易失效条件 |
|---|---|---|
| 当前暗谷 `V_cur(s)` | 该处当前是否有线状暗结构？ | 划痕、阴影、孔缘、闭合裂纹 |
| 参考暗谷 `V_ref(s)` | 参考图对应材料点是否已存在暗结构？ | 配准错误、参考已有裂纹、光度变化 |
| 正规化新增暗谷 `ΔV(s)` | 当前是否比可信参考出现新的线状证据？ | 局部拉伸、反光、已有裂纹张开 |
| 局部残差 `D(s)` | 背景光度补偿后，增量变化是否沿线局部集中？ | 运动边缘双影、低纹理 |
| 两侧对比 `Q(s)` | 暗线中心与两侧材料的局部差异是否显著？ | 复杂背景、线宽变化 |
| 方向/连续性 `G(s)` | 该段是否沿既有主干继续而非跳到交叉纹理？ | 强弯曲、S 型和静态纤维交叉 |
| 局部可观察性 `O(s)` | 参考对齐和光度残差是否足以支持上述比较？ | 低纹理、饱和、遮挡、区域越界 |

实现要求：

1. 逐点或逐 tile 保存特征、可信性和**路径弧长坐标**，不得仅保存一个整条路径平均 `reference_ratio`。
2. 必须保留有序证据序列，分析新裂纹与旧纹理的可能交接；对**当前图形态近似相同**的真假尾参考配对，检查是否存在统计上可分的增量特征。
3. 对当前暗谷很强、参考暗谷也很强的区域，不能仅凭“参考有暗线”判为假裂纹；可能是真裂纹穿越静态纤维，也可能是参考图已有裂纹开口变化。
4. 对高曲率、交叉和弱渐浅区域，不要把第一个负变化点/失支持点直接作为尖端；比较前后**一段持续性**和不同停止假设。支持 `NO_VISIBLE_CHANGE_BUT_CURVE_CONTINUES`、`REFERENCE_ALIGNMENT_UNKNOWN` 等明确诊断状态。
5. 建立候选级 `NEW_CRACK_SUPPORTED / STATIC_OR_BRIDGE_RISK / INSUFFICIENT_EVIDENCE` 三态；`STATIC_OR_BRIDGE_RISK` **不是一票否决**。不允许将局部光度/几何验证状态与裂纹归属状态混为一谈。
6. 使用新 DEV 的**已知端点合成配对**校验所有量的符号、尺度、单调性、可靠性和反例；不要从已曝光 C2 TEST 的分布（例如 `reference_ratio` 数值）直接抄参数。

**必须进行的纯因果消融：** 仅当前图、当前+原始参考差分、当前+可信几何配准、当前+可信配准/光度、当前+可信增量沿路径统计、当前+增量+轻量时序（如合法可用）。每次只新增一个可归因机制，报告共同确认配对变化。

### M4. 在原 DP 内保留少量停止候选（而非重写搜索器）

- **原冻结 A 的尖端始终原封不动地保留在候选集合**，不得平均、吸附、投影、截断或被自动删除。
- 对每个通过的延伸 tile，在已有 DP 计算中记录少量**具有独立意义的**候选：局部证据持续减弱、参考归属变化、分支竞争、末端法向重定位、原生停止点；保留 tile 对应原始高精度路径点和证据。限制全帧最多 K 个候选，K 及排序约束必须在 DEV 预注册。
- 候选的生成与评价要分离：不能凭已知 TEST GT 把候选插入正确位置；不许用 GT 对候选做在线排序。
- 为每个候选记录 `origin`、`arc_s`、原图 `(x,y)`、局部路径方向、图像证据、参考可信域、候选前后响应、CPU 开销及与 A 原尖端距离。
- 如原生 A 无有效尖端，但已有可重放的局部路径/种子，可产生有限局部候选；**不要为了提高覆盖率重新扫描整个 ROI**。
- **关键反例**：一条静态纤维与真实裂纹交叉，不可将 `REFERENCE_OWNERSHIP_TRANSITION` 默认优先于 A；无可信参考时不要伪造早停止候选的可信标签。

### M5. 独立尖端决策：多证据比较，不再把 DP 停止视为尖端真值

保留两个独立逻辑：
- `DP_STOP_REASON`：搜索为什么停；
- `TIP_DECISION`：为什么认为某个候选是可见裂纹尖端（或为何不可判）。

必须实现：

1. A 原尖端与新候选的**同证据口径**比较，允许 `KEEP_A`、`REPLACE_WITH_EVIDENCE`、`NEW_TIP_WHEN_A_INVALID`、`AMBIGUOUS/UNKNOWN`；不得简单总优先选择“参考过渡点”。
2. 避免 C_FULL 旧式多个阈值全 AND、一项未知即全拒绝，也避免“参考已有暗线→立即截短”的 C2 误判。条件可包含可信度检验，但**证据 UNKNOWN 不等于 CONTRADICTED**。
3. 评估两种候选差异：几何位置是否分叉、段落是否持续新增、参考静态纹理是否贯穿前后、当前暗谷是否仅终止于纹理端点、外推和路径方向是否合理、候选前后可靠观察范围是否足够。
4. 对真假尾成对测试与真实裂纹穿越旧纤维测试要求同时成立；不能只优化假尾并牺牲真长、弱裂纹、曲率大的已正确 A。
5. 对于已有 A 有效尖端且缺乏可信反证的帧，研究版必须**单独记录**“研究证据不足、保留 A 原生输出”的状态；这不是新算法已正确的证据。
6. 对确实不可辨识的输入允许输出 `AMBIGUOUS/UNKNOWN`，但不得用大量撤销已正确结果换取低 FP；需计入总损失和覆盖率。
7. 决策必须可复现、可审计：提供逐候选评分分解与反事实（去掉参考图/交换参考/禁用光度）的预测差异。

**推荐先保留简单、可解释的排序规则或经过 DEV 校准的低维证据模型；不得添加深度网络、数据集标签分支或在线自学习。** 不要求必须使用机器学习拟合器；如果使用监督标定，也只能在 DEV 的程序真值上完成、冻结后上线，不得称为“完全零先验”。

### M6. 可选的轻量时间支持（仅研究，缺少同步信息则 UNKNOWN）

- 如果实时系统合法持有过往参考帧/变形帧，在相同材料坐标下记录候选末端附近的**局部证据时间序列**。确认不能只检查起始前缀；必须包含候选末端区域。
- 不假设帧号等于加载相位，不强制路径长度单调增长，不用未来帧；若无相位输入统一 `PHASE_UNKNOWN`。
- 仅对已有少量候选使用上一帧缓存的窗口与响应，不设计全图运动场；此模块必须可单独禁用并测试是否真正增益。

## 4. 最关键的实验设计：必须能够推翻错误假设

### 4.1 DEV：先在新 DEV 中实现并淘汰无效机制

建立与旧数据不同的**新背景、随机种子、生成参数和样本组合**，并为每个案例记录：参考图、当前图、P1/P2、程序独立已知可见尖端、裂纹/旧纹理的几何、各材料像素真值与输入 SHA-256。

必须覆盖：

- **完全相同的当前图 + P1/P2、不同参考图**的真假长尾配对；须包含灰度非常相近、局部暗谷结束位置相同的难例；
- **真实裂纹穿越参考图已有静态纤维/划痕**，避免 C2 已发生的 55° 弯曲误伤；包含 55°、75° 和 S 型；
- 真实长裂纹、渐浅弱裂纹、短裂纹萌生、部分闭合/参考已存在裂纹、参照图本身含暗线、可见尖端难以精确分辨；
- 长距离连续高分静态假纹理（要实际使冻结 A 出现长尾，而非只做图像看似相似的样本）、假分支、孔缘错位、亮度漂移、局部阴影、强反光、低纹理和非刚体扰动；
- 相机分辨率/像素宽度变化、不同 P1/P2 标距、全图/局部高噪声、不同灰度量化；
- 预期无裂纹的阴性、静态暗线阴性、孔洞运动阴性、不可观察正例单独分层。

**难例激活审查：** 对强假尾族，必须实际重放冻结 A 并证明产生足量的错误长尾；否则该测试不能用来宣称“已解决排除组X 473 机制”。对照真长裂纹必须有匹配难度；程序端点由生成器定义，不得从算法预测反推。

**自适应跨场景合同：** 所有规则只能是同一套图像可观测特征公式与统一边界，例如候选局部线宽、噪声 MAD、材料纹理可匹配性。禁止 `if group == ...`，禁止保存某试件预调参数文件，禁止从图像 SHA / 路径 / 文件名隐式识别组别。

### 4.2 预注册冻结，随后一次性新 TEST

流程：

1. 完成 DEV 选择，**在 TEST 生成前锁定**代码、参考缓存策略、生成器、评价器、机制开关、所有阈值/上限、失败返回规则、bootstrap 采样单位和发布门槛。
2. 记录所有文件 SHA-256、源码提交/工作树状态、运行环境、随机种子及权限边界；执行可重放合同测试和输入处理测试。
3. 在锁定后生成新 TEST，先封存全部图像/GT/身份哈希，再启动检测；TEST 仅允许一次性冻结执行。失败不能更换种子、删案例或后验改阈值。
4. TEST 与 DEV 至少在**独立背景生成源/种子/基础材料纹理**上隔离；共享当前图的真假尾对属于一个聚类，不能当作独立样本。检查案例/图片/GT 哈希重叠并提供证据。
5. 旧 C、C2、A、六组真实图、三点弯和排除组X所有关键帧全部标记 `EXPOSED_DIAGNOSTIC`。可以在其上解释失败、验证不回归，**不得作为新 TEST 或调参后独立成功证据**。
6. DEV 门槛已失败时，原则上停止晋级；若为了诊断仍在预锁定方案上运行 TEST，必须明确 `DIAGNOSTIC_TEST_ONLY`，不得利用好看的 TEST 结果翻案。

### 4.3 必须设置的机制对照与负控

- CURRENT_ONLY（不读取参考及其派生状态）；
- P1/P2 纯刚体 + 未验证差分（**只用于诊断，禁止生产确认**）；
- 可信局部配准、可信配准 + 光度、再加沿路径新增证据；
- 去掉参考归属证据的 A′；
- 交换配对参考图、参考遮蔽、静态图误配对、低纹理与虚假高 NCC 匹配；
- 原生 A 端点是否保留、是否引入提前停止候选、是否开启局部时序的消融；
- 搜索 ROI 放大但固定审核证据；审核 ROI 放大但固定 A/备选路径；
- 输入顺序、文件名、数据集目录名、无参考/无 history 的元数据不变性测试；
- 使用没有裂纹的参考图、包含初始裂纹的参考图，检验参考判别不作不实物理假设。

**识别能力测试**：对于共享当前图与 P1/P2 的配对，如果禁用参考证据，其两种输出必须相同；如果启用可信参考，必须检验是否有真实新增区分，而非仅对 TEST 标签作了分支。

## 5. 度量与发布门槛（必须预注册，不能只看条件 MAE）

### 5.1 统计单元与分层

每条记录至少包含 `(case_id, render_pair_id, frame_id, side, algorithm, input_sha256)`，各方法同帧严格配对。

- 可观察正例：确认覆盖率、已确认条件 MAE/P95、二维尖端误差 `≤8 px` 数量（8 px 为**历史研究比较阈值**，不是物理容差）、全部正例拒绝惩罚损失、错误长尾/过早停止、水平投影长度误差。
- 阴性：误确认率及数量；不可观察正例另列，不准合并成真阴性或隐藏。
- 相对于 A：**新增修复**、**A 原正确遭改错**、**A 原正确遭撤销**、**A 错误仍保留**、候选存在但选择失败、原生 A 无输出时新候选的正确/错误确认。
- 假长尾与真长必须**按配对案例**计算“两端均正确”，不能仅报告帧级平均；静态纤维交叉、55°/75°/S 型、弱渐浅、孔缘运动、曝光变化必须单独分层。
- bootstrap 按独立 case / shared render pair 分层聚类，不能把重复帧当独立样本；注明 CI、样本量、预注册差异与效果量。
- **真实六组无物理 GT**：只报告覆盖、差异、参考有效性、运行时间、可视化和异常风险。没有人工/物理真值时，真实 MAE 和“改进正确帧数”必须写 `N/A`。

### 5.2 建议准入门槛（请在新 TEST 前预注册为不可更改的规则）

| 门槛 | 最低要求 |
|---|---|
| 冻结 A 保持 | 生产源码/DLL/ABI/参数/正式输出哈希不变；原生重放一致 |
| 核心正确性 | 新 TEST 的 `≤8px` 正确帧总数严格优于 A；全正例配对惩罚损失不劣于 A，优选有聚类 CI 支持的下降 |
| A 正确结果保护 | **不得出现 C2 式 160px 级灾难性改错**；以“正确 A 改错或撤销 = 0”为首选硬安全门槛；若样本规模不足以证明为零风险，必须如实说明 |
| 真假长尾 | 至少一个足量独立 pair 子集实现非零、可重复的两端同时正确；不可仅通过拒绝假尾而牺牲匹配真长 |
| 弱/弯曲保护 | 55°、75°、S 型、渐浅、真实长裂纹的正确数不得出现有意义下降；单独报告极端风险 |
| 阴性虚警 | 不高于 A 基线，且不能通过大量拒绝正例换取改善 |
| 参考信息可靠性 | 在新的不同背景及已曝光真实回归上报告局部 FIT/HOLDOUT 成功率、失败原因、空间可用域；**不能因为覆盖率低就放松验证** |
| 泛化 | 同一源码/同一参数生成规则、目录名和试件名称不参与判断；新真实试件无人工调参运行 |
| 实时性 | 独立新 C++17/OpenCV4.4 原生完整核心（含 A′ 所有必要模块）各帧 `≤66.67 ms`，并提供 P50/P95/P99/Max、最慢组、冷/热运行情况；端到端另测 |

如果**DEV 有正确 A 被重大损坏**，不能以 TEST 聚合 MAE 好看为理由直接发布。若无法保证零损坏，可预注册统计非劣效界限，但不得在看过 TEST 后移动门槛。上述具体零损坏等属本任务建议的研究安全原则，并非此前所有报告已验证的通用工业标准。

### 5.3 性能策略

- 参考图特征、材料掩膜、初始统计、参考 ROI/纹理梯度必须在**加载参考帧时缓存一次**；单帧只做增量且局部的处理。
- 每帧复用 A 的灰度缓冲、现有运动映射、tile 响应；候选数量固定上限，审核窗口固定小面积、原图像素尺度；不做第二套全图 Frangi / DP / 大图非刚体配准。
- 将帧耗时分解为 `legacy_A_ms / reference_registration_ms / photometry_ms / path_evidence_ms / endpoint_decision_ms / total_native_ms`；使用统一计时边界（`Process + GetResultV2 + CopyPath + 必要内存分配`），预解码/编码另列。
- A 历史最慢帧曾接近 61.6ms，因此不能假设新模块“平均耗时低”就符合实时预算；必须在最慢材料和极端背景下验证最大耗时。若超预算，只能做等效缓存/局部裁剪/数据结构优化，不能无依据跳过困难帧或降低证据审核标准。
- 未通过 DEV 效果门槛时，允许只保留轻量原生实验插桩或 Python 研究，不发布新 DLL；**性能未测试必须标记 NOT_TESTED，而不是估计通过**。

## 6. 开发实施顺序（必须真正改源码、执行实验与留证据）

**Gate 0 — 基线完整性与接口审计：**

- 冻结 A 重放并进行哈希验收，定位已有可复用缓冲；明确当前工程的真实路径与 build 命令；产出合同文档、基线逐帧 CSV。

**Gate 1 — 参考信息可用性单独研究：**

- 实现 M1/M2 的自适应材料块选择 + 稀疏局部配准 + 光度验证；先不改变任何 A 尖端。对六组已曝光真实图做只读有效性审查，回答过去仅 2/3035 通过究竟是**缺少纹理、块位置不对、验证范围不覆盖候选、光度模型不适用，还是其他原因**。报告真实有效域，不允许以新增 UNKNOWN 隐藏失败。
- 若真实参考仍几乎完全 UNKNOWN，优先修复“能否公平比较参考”的基础能力，不进入自动截短决策。

**Gate 2 — 参考增量的辨识性单独研究：**

- 实现 M3 分段证据；在新 DEV 上对真假尾配对、穿越静态纤维、弱渐浅、不同照明进行盲于 GT 的响应计算。研究新证据是否确有**候选级分辨能力**；必须呈现负控、证据分布、可评价域与失败图册。
- 如果可靠新信息在难例中不可区分，明确 `INSUFFICIENT_INPUT_INFORMATION`，不要继续叠加同源灰度阈值。

**Gate 3 — A′ 内部极小改动与候选决策：**

- 在单独 A′ C++ 分支中增加 M4 限量停止候选及 M5 独立尖端选择，冻结 A 原尖端保底，保留原输出及新输出双通道。逐项消融，先保护正确 A，然后要求真正修复 A 错误尖端；不把过度保守视为收益。
- 研究阶段允许先用 Python 检验指标与候选规则，但决定晋级时必须使用与原生实现一致的数学定义与回放结果，不允许“Python 成功、C++ 不同”却宣称成功。

**Gate 4 — 预注册新 TEST：**

- 源码与生成器锁定、数据隔离检查、一次性新 TEST、case/pair 聚类统计、最低安全门槛判决。失败时立即止步、保留失败例证，不改 TEST 参数、不更换种子。

**Gate 5 — 新 C++ 生产候选（仅研究准入通过时）：**

- 单独构建 DLL/EXE，不覆盖原 A；ABI 变更另行版本化。全部组回归、原图像素坐标与路径验证、完整原生时延及内存验证、真实已曝光组旁路对照；另安排新真实试件冻结运行。未通过实际端点/安全与实时两类条件时依旧 `KEEP_A`。

**硬要求：**每一 Gate 必须有通过/失败判定和证据文件；不允许只输出计划、伪代码或单个成功案例截图。Agent 应独立执行可执行的工作；若缺少原图或原 DLL，必须明确阻塞位置与已完成任务，不能编造运行结果。
