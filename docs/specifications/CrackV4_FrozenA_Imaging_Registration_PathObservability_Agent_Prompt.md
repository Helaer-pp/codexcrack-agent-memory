## 3. 实验 A：成像与光度可用性审计（不改变原图或 A 运行）

### 3.1 全组逐帧基础画像

原四组所有帧执行；统计至少下列指标，并按试验组、时间阶段、是否 A 完整确认以及图像位置分层：

1. 图像尺寸、bit depth、实际有效动态范围、黑白饱和比例（全局和裂纹 ROI）、P1/P2 周围区域掩膜有效性；不以固定 8-bit 假设处理 12/16-bit 输入。
2. 稳健亮度、对比度：背景区域 median、IQR、P01/P99、局部光照梯度、帧间变化；静态背景取样必须避开孔洞、明显非材料区域、裂纹候选带和饱和区域。
3. 噪声估计、局部纹理对比、方向性背景线条密度；说明自然纹理可能包含潜在裂纹，背景标签仅为**工程对照假设**。
4. 清晰度：梯度能量/局部边缘扩展或 MTF 代理指标、明显运动模糊方向与幅度、可见线宽与像素采样比例；这些只能叫图像清晰度/解析能力代理，不当成相机真实 MTF 的绝对测量。
5. 沿 A 路径固定点位的**原始灰度横截面**与邻近两侧背景（仅离线读图）。分别统计主体前段、主体中段、异常证据区和尾段；防止在单一尺度下错把渐浅裂纹当成无裂纹。
6. 检查不同时刻的曝光、加载相位、反射变化是否有可靠元数据；无元数据时只报告可观测的影像差异，不猜测原因。

### 3.2 受控仿真与反事实

在**不改变底层真实裂纹几何**的可逆亮度、噪声、轻微模糊与几何扰动中，独立测量：

- 诊断的光度/路径证据变化；

必须准备光照渐变、局部阴影、轻微过曝、弱暗线、静态划痕与相机平移的**负对照**。无真实 GT 时可以检验对已知施加的扰动是否不变，但不能把某个稳定结果当成正确路径。

## 4. 实验 B：全局两点与局部材料配准的独立核查

**禁止用参与拟合变换的两个 P1/P2 自身的拟合残差，宣称全路径的局部配准误差很小。** 两个点足以决定一种二维相似变换，拟合点内部残差可能天生接近零，不能成为独立检验。

### 4.1 基线几何复盘

- 对于只有两点能支持的变换，不声称可校准任意仿射/非刚性形变。

### 4.2 独立局部材料特征验证

只用于**离线诊断**，允许使用 OpenCV 传统局部模板匹配、相位相关或特征点匹配，禁止深度学习或用其输出替换生产路径。

- 在孔边缘之外的**稳定材料背景**设置多个局部 ROI，并额外设置**裂纹路径周围但避开裂纹本体的两侧材料 ROI**；自动剔除低纹理、饱和、模糊、裂纹跨越、边界超出的候选 ROI。
- 预先固定 ROI 选择策略，不以第五组特点人工挑选最佳点；使用空白或低纹理 ROI 时必须标记不可评价，不准制造置信度。

- 采用空间上分离的 ROI 来拟合与验证（held-out）局部运动，**不能同一批点既拟合又报告其残差作为独立误差**。
- 测量残差随图像位置、裂纹弧长、距锚点距离、试验进程和加载状态的变化；区分真实材料变形、曝光改变和匹配失败三种可能性。
- 避免错误结论：高残差可能是配准不足，也可能是材料真实变形、纹理重复或不可匹配；低残差也不证明尖端正确。

## 5. 实验 C：冻结 A 路径的可辨识性诊断（不得重新定位尖端）

### 5.1 路径分类必须叫「证据形态」，不能叫真值标签

在每帧 A 路径上离线计算若干**互补且来源清楚**的观测：

- 当前帧中心与两侧背景的横截面对比及空间连续性；
- 已有参考纹理与当前纹理的一致性（仅在局部配准可信时允许解释为新增/既有证据）；
- 沿路径灰度变化、局部线宽、远离孔边缘的背景线密度；
- 独立材料配准可信度和光度可信度；
- 与冻结 A 的候选输出、完整确认和上一帧状态对应的时间索引。

分成以下**研究诊断类别（可重叠且可为 UNKNOWN）**：

1. `PATH_SUPPORTED_TO_TAIL`：到末段仍有可观察线形态支持；**不等于尖端正确**。
2. `TAIL_EVIDENCE_FADE`：仅尾段证据持续减弱；**可能是真尖端也可能是弱裂纹**。
3. `BODY_EVIDENCE_DISAGREEMENT`：路径主体较早出现持续证据分歧；**不代表该区段一定无真实裂纹**。
4. `REGISTRATION_UNRELIABLE`：当前参考比较不可靠，不能使用差分推断裂纹生长。
5. `PHOTOMETRY_UNRELIABLE`：曝光/亮度变化使基于变化的证据不可解释。
6. `LOW_OBSERVABILITY`：裂纹状结构与局部背景在实际成像条件下无法稳定区分；仅为**诊断风险**。
7. `UNCLASSIFIABLE`：样本不足、观测冲突或算法条件不满足。

不允许将这些类别自动回写为 `tip_valid` 或 `length_valid`。即使发现明显路径主体失证据，也只能给出候选风险区段、原因和观察图，不得把区段边界称为物理尖端。

### 5.2 对照设计：解决此前负对照分母为零的缺陷

上一轮 12 张无新增 TEST 图像均未获 A 完整确认，导致 T 可评价分母为零。本轮必须设计真正**覆盖算法输出状态**的对照：

- `N0`: 无已知新增裂纹、A 未确认（负对照，只可评价 A 无确认下的观测质量）；
- `N1`: 无已知新增裂纹但**A 确认**的受控工程对照（优先从原四组真实背景构造可复现可评价情形；如无法构造，明确 `N1=0/NOT_TESTABLE`，不能谎称 0 误报）；
- `P1`: 在真实背景上程序注入有已知中心线、端点的裂纹且 A 确认；
- `P2`: 同类注入但 A 未确认或过早停止；
- `P3`: 注入逐渐变浅、短间断、闭合/曝光扰动的裂纹；
- `B1`: 含静态纹理、强暗线、划痕样结构的背景对照。

程序注入的几何端点为**合成 GT**；同时用可观察性检查确认末端是否在成像中保留足够信号，**不能把几乎消失的注入曲线当作算法必然能识别的真实可见裂纹**。按试件背景、强度、曲率、宽度和扰动条件分层统计；采用不重叠或足够隔离的测试裁剪，避免同一背景纹理落入开发与测试。

### 5.3 对照算法不能从结果中创造真值

- 对 A 全部正式确认与未确认帧统计诊断类别、路径总长度、**主体分歧开始位置 / 路径长度**、末段证据统计和不可评价原因。
- 对 A 仍能确认但路径证据可疑的帧，保存完整可复核的图像/横截面；不单凭某个指数称其「真正错误」。
- 研究背景得分：仅在原有 DP 主机理允许下，对匹配位置、宽度、长度及搜索自由度的背景 ROI 运行**离线对照评分**，防止把普通单像素背景值错误地用作 DP 最优路径的负样本分布；**不得接入或修改生产 A**。
- 对非自然变化（加亮、过曝、平移、错位）做已知干预，检查诊断类是否合理反应；对真实数据不能给出真实 tip MAE。

## 7. 实验 E：测量问题、场景问题和计算性能必须分开

## 8. 核心判定：只回答哪种研发投入才有价值，不发布新算法

每组分别回答并给出证据：

1. **成像受限**：是否有饱和、低对比度、模糊、反光或曝光变化，达到足以淹没弱线增量的程度？证据是可观察 SNR/扰动/背景分布，而非主观形容。
2. **局部材料配准受限**：在独立背景 ROI 中，A 的全局 P1/P2 变换是否留下显著、可重复、并与局部位置有关的残差？这些残差是否大到足以污染参考差分？如果对照也不可匹配，则结论为 `INCONCLUSIVE`。
3. **主体路径选择受限**：A 的候选路径是否在主体出现可重复的证据分歧？在可靠成像/配准子集中是否仍然存在？若是，结论为「现有固定路径后验不能修复」；但不能擅称真实路径在哪里。
4. **可辨识性不足**：受控合成中裂纹与静态纹理的特征分布是否明显重叠，且在现实幅度的扰动下识别不稳？无法区分时说明适用条件与风险，并明确哪些结论仍缺真实 GT。
5. **门控/评估不足**：是否因为可评价率过低、样本选择或负对照分母为 0 导致根本无法证明方法价值？用实际分母证明。
6. **系统性能**：生产 A 是否在指定硬件上达标？离线诊断不计入生产 15 Hz 结果，但不应误用两者耗时。

### 8.1 输出一个有条件的决策矩阵

| 验证结果 | 下一步建议 | 本轮禁止行为 |
|---|---|---|
| 光度/模糊/饱和主导 | 优先给出曝光锁定、补光、镜头/对焦、加载相位一致性等**具体可验证采集建议**，并提出可用对照 | 直接换滤波器并宣称尖端更准 |
| 独立材料配准残差明显且可估 | 单独立项研究局部材料坐标模型及观测质量，不接入当前 A | 在本轮擅自改配准／根据排除组X调参 |
| 成像/配准可评价但路径主体持续失证据 | 判断固定 A 的后验方案存在能力边界，建议独立研究路径选择问题或采集额外证据 | 再增加尾端阈值或假称真实尖端可恢复 |
| 图像证据强烈重叠／观测不足 | 说明算法无法仅靠当前输入保证所有场景的真实尖端，提出增加采集信息的选项和成本 | 虚报精度、发明物理真值 |
| 对照或有效分母不足 | 标记 `INCONCLUSIVE`，补充**无需人工真值**的已知工程对照方案 | 把零分母当 100% |
| 主要问题无法区分 | 给出证据限制与最小下一轮可证伪实验 | 泛泛归因“阈值不合理” |

报告必须明确建议是：`KEEP_FROZEN_A`、`IMPROVE_IMAGING_FIRST`、`STUDY_LOCAL_REGISTRATION_SEPARATELY`、`STUDY_PATH_SELECTION_SEPARATELY` 或 `INCONCLUSIVE`；可多选，但不能声称已提升真实裂纹精度。
